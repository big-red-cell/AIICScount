# Issue 326175281__a736b10ccb

**Bucket:** REPRODUCED

## Summary
Chrome executes `javascript:` URLs stored as bookmarks in the context of the currently open page. A bookmark created from the issue's "Anti-bot Checker" picture link runs `window.alert(document.cookie)` in the open page's context and exposes that page's cookies; verified end-to-end: the alert message was exactly `session=SECRET12345`, the cookie of the open "logged-in" service page.

## Environment
- OS/runtime: Windows 10.0.26200 (x64), PowerShell 7 shell, Node v24.13.1
- Browser: Google Chrome 151.0.7922.174 (`C:\Program Files\Google\Chrome\Application\chrome.exe`), fresh isolated profile under `repro/issue_326175281__a736b10ccb/profile`
- Automation path: CDP over WebSocket (`--remote-debugging-port=9222`, Node driver `cdp.js`) + Windows UI Automation (UIA InvokePattern) for the bookmark-bar click
- Required environment (per issue): "Chrome Version: all / Operating System: all" — satisfied by local Chrome plus a localhost HTTP "logged-in" page
- Attachments used: none (the gstatic image URL from the issue text was referenced directly inside the crafted HTML; no download needed)

## Reproduction

### Steps executed
1. Preflight: killed existing Chrome and prepared an isolated profile.
   - cmd: `Get-Process chrome -EA SilentlyContinue | Stop-Process -Force`; `New-Item -ItemType Directory -Force -Path ...\profile`
   - verify: output `chrome-clean`; browser version read from file: `151.0.7922.174`

2. Built the issue's HTML file (issue reproduction steps 1–2).
   - cmd: wrote `repro/issue_326175281__a736b10ccb/antibot.html` containing `<a href="javascript:window.alert(document.cookie);"><img src="https://ssl.gstatic.com/ui/v1/icons/mail/rfr/logo_gmail_lockup_default_2x_r5.png" alt="ANTIBOT CHECK"></img></a>`
   - verify: file exists (175 bytes, SHA-256 `4555AA819D4ADA8CF659AE3CAB3B78505E89F13D920065CBBDB4B4D52D824553`); opened in Chrome and read back via CDP: `NAV_RESULT: file:///.../antibot.html`; DOM readback `{"href":"javascript:window.alert(document.cookie);","alt":"ANTIBOT CHECK","tag":"A"}`

3. Replicated the bookmark-bar state that issue step 3 (drag-and-drop) produces, by injecting the bookmark into the profile's bookmark store (`profile\Default\Bookmarks`, "Bookmarks bar" root).
   - cmd: wrote Bookmarks JSON entry `name=ANTIBOT CHECK`, `url=javascript:window.alert(document.cookie);`
   - verify: post-launch readback of `profile\Default\Bookmarks`: `bookmark-name=ANTIBOT CHECK url=javascript:window.alert(document.cookie);`; bookmark bar made visible via preference `bookmark_bar.show_on_all_tabs=true` (page viewport height dropped 807→773 px); the bookmark button exposed in the browser UI UIA tree: `UIA_FOUND: name=ANTIBOT CHECK controlType=ControlType.Button enabled=True`

4. Set up the "website you are logged in to" (issue step 4): local HTTP server that sets a session cookie, and navigated to it.
   - cmd: `node service_server.js` (listening 127.0.0.1:8899, `Set-Cookie: session=SECRET12345; Path=/`); `node cdp.js nav http://127.0.0.1:8899/`
   - verify: CDP readback `{"url":"http://127.0.0.1:8899/","title":"Logged-in Service","cookie":"session=SECRET12345"}`

5. Clicked the bookmark (issue step 4) via UIA InvokePattern while a CDP `Page.javascriptDialogOpening` listener was attached.
   - cmd: `node cdp.js wait-dialog 25` (background listener) then `powershell -File uia_invoke.ps1`
   - verify: `UIA_INVOKED`; CDP event received: `DIALOG_OPEN: message="session=SECRET12345" type=alert url=http://127.0.0.1:8899/`; dialog accepted: `DIALOG_ACCEPTED`

6. Post-trigger readback.
   - cmd: `node cdp.js eval "JSON.stringify({url: location.href, cookie: document.cookie})"`
   - verify: `{"url":"http://127.0.0.1:8899/","cookie":"session=SECRET12345"}` — page unchanged; the alert message matched the page's live `document.cookie` value exactly.

Observable effect: clicking the `javascript:` bookmark while the service page was open produced an alert whose message is exactly that page's cookie value (`session=SECRET12345`). The bookmark script executed in the context of the open page and read its cookies — the effect described by the issue.
