# Issue 40946335__00297a941d

**Bucket:** POTENTIAL

## Summary
A Chrome extension using `declarativeNetRequest` redirects a subresource loaded inside a cross-origin out-of-process iframe (OOPIF) of chromewebstore.google.com to a `data:` URL, causing script execution (alert) on the privileged Web Store page. The required PoC extension (the only artifact containing the exact redirect rule and target resource) could not be obtained in this environment, so the observable effect was not verified.
