# Issue 466994972__606cf0e196

**Bucket:** REPRODUCED

## Summary
The issue claims Chrome's download UI misattributes the source of a downloaded
file: after clicking a link on the Google redirect page
(`https://www.google.com/url?q=https://dist.torproject.org/tor-0.4.8.21.tar.gz`),
`chrome://downloads` shows the download as coming from `https://www.google.com`
even though the file is served from `dist.torproject.org`. This observable
behavior was reproduced end-to-end and verified via CDP DOM readback, the
profile History database, and the downloaded file on disk.

## Environment
- OS/runtime: Windows 10.0.26200 (x64), PowerShell 7, Node.js v24.13.1 (CDP driver), Python 3 (SQLite readback)
- Browser: `C:\Program Files\Google\Chrome\Application\chrome.exe`, version 151.0.7922.174
  (issue reported against 143.0.7499.40; behavior persists on the installed newer version)
- Automation path: CDP over `--remote-debugging-port=9222` on an isolated fresh
  profile (`artifacts/reproduction/repro/issue_466994972__606cf0e196/profile`);
  `Runtime.evaluate` DOM readback + `Input.dispatchMouseEvent` real user click
- Required environment: desktop Chrome + public network access to
  `www.google.com` and `dist.torproject.org` (both reachable from this host)
- Attachments used: none

## Reproduction

### Steps executed

1. Preflight: verified Chrome binary and killed stale Chrome processes.
   - cmd: `Get-Process chrome -EA SilentlyContinue | Stop-Process -Force` then `(Get-Item "C:\Program Files\Google\Chrome\Application\chrome.exe").VersionInfo`
   - verify: process list returned `clean`; version read back as `151.0.7922.174`

2. Launched isolated Chrome with a fresh profile and CDP port.
   - cmd: `Start-Process chrome "--user-data-dir=<...>\profile --remote-debugging-port=9222 --no-first-run --no-default-browser-check"`
   - verify: `Invoke-RestMethod http://127.0.0.1:9222/json/version` returned `Chrome/151.0.7922.174`

3. Navigated a new tab to the Google redirect page from the issue steps.
   - cmd: CDP `Page.navigate` to `https://www.google.com/url?q=https://dist.torproject.org/tor-0.4.8.21.tar.gz`
   - verify: read back `location.href` = `https://www.google.com/url?q=https://dist.torproject.org/tor-0.4.8.21.tar.gz`, `location.origin` = `https://www.google.com`, `document.title` = `重定向声明` (Redirect Notice); page contains an anchor with text `https://dist.torproject.org/tor-0.4.8.21.tar.gz`

4. Clicked the link with a real mouse input (user activation).
   - cmd: CDP `Input.dispatchMouseEvent` (mouseMoved/mousePressed/mouseReleased) at anchor center `(x=378.6, y=107.9)`
   - verify: anchor read back before click: `href=https://www.google.com/goto?url=...`, `text=https://dist.torproject.org/tor-0.4.8.21.tar.gz`; after click the tab remained on the Google page (download initiated in background)

5. Confirmed the download completed and the file is on disk.
   - cmd: `Get-Item "D:\Downloads\tor-0.4.8.21.tar.gz"` + `Get-FileHash`
   - verify: `Length = 10663112` bytes, `SHA256 = EAF6F5B73091B95576945EADE98816DDFF7CD005BEFE4D94718A6F766B840903`; remote HEAD of `https://dist.torproject.org/tor-0.4.8.21.tar.gz` reports `Content-Length: 10663112`, `ETag: "a2b4c8-643ce24bdb3c0"` (matches; file type `application/x-gzip` per History DB)

6. Read the `chrome://downloads` entry via shadow-DOM traversal (CDP).
   - cmd: `Runtime.evaluate` on `chrome://downloads` locating the `downloads-item` shadow root
   - verify: `#initiator-origin` text = `来自 https://www.google.com` (i.e. "From https://www.google.com"); `#fileLink` href = `https://dist.torproject.org/tor-0.4.8.21.tar.gz` — the UI attributes the download to `https://www.google.com` while the file URL is on `dist.torproject.org`, exactly the observable described in the issue

7. Corroborated via the profile History database (Downloads table).
   - cmd: copy `profile\Default\History` → `History_copy2.db`, `sqlite3` query of `downloads`
   - verify: row id=10: `target_path = D:\Downloads\tor-0.4.8.21.tar.gz`, `state = 1` (complete), `received_bytes = total_bytes = 10663112`, `referrer = https://www.google.com/`, `tab_url = https://www.google.com/url?q=https://dist.torproject.org/tor-0.4.8.21.tar.gz`, `mime_type = application/x-gzip`
