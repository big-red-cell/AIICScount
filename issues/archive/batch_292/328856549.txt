ma...@chromium.org： <p>The POC defines a custom iframe element via <code>customElements.define</code> that listens for changes to its <code>src</code> property. It then fetches the URL via a proxy URL that strips the <code>X-Frame-Origin</code> header, and assigns the resulting source to the iframe&#39;s <code>srcdoc</code>. The custom iframe element is only used for elements that specify <code>is=&quot;x-frame-bypass&quot;</code>.</p> <p>This is working as intended.</p>
