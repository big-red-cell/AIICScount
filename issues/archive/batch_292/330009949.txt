ma...@mindedsecurity.com： VULNERABILITY DETAILS:<br>The following bug describes how the user&#39;s password is logged in the developer&#39;s console due to a Chrome-generated warning.<br>When developers do not set an &quot;autocomplete&quot; attribute within the input tag for a password input, the user&#39;s browser raises a warning log message. After the user writes his password inside the input tag, the attribute value is<br>reflected in the warning log.<br>An attacker who is able to access the victim&#39;s browser developer console can steal this secret information.<br>Moreover, if an attacker, via social engineering attacks, is able to induce the victim to export and send his<br>console logs, can steal the victim&#39;s password.<br><br>POC:<br>The attached file describes how to replicate the issue.<br><br>SUGGESTED REMEDIATION:<br>Inside the PoC file.<br><br>VERSION:<br>- Windows 10 with Google Chrome 122.0.6261.129 official build<br>- Ubuntu 22.04 with 121.0.6167.184 official build<br><br>CREDIT INFORMATION:<br>Reporter credit: Marco Gasperini
