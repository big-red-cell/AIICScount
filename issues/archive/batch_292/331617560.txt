bu...@google.com： <hr> <h3>Report description</h3> <p>CSP bypass via the use of same-origin iFrames</p> <hr> <h3>Bug location</h3> <h4>Which product or website have you found a vulnerability in?</h4> <p>Google Chrome</p> <hr> <h3>The problem</h3> <h4>Please describe the technical details of the vulnerability</h4> <h2>Introduction</h2> <p>Content Security Policy (CSP) serves as a security mechanism for web applications, primarily aimed at mitigating cross-site scripting (XSS) attacks. However, scripting in iFrames is still allowed, even scripting on CSP enforced same-origin parents/children.</p> <h2>Technical Details</h2> <p>The vulnerability stems from the ability of iframes with the same origin as the parent page to execute scripts within the parent&#39;s context, irrespective of CSP blockings. The technical process involves:</p> <ul> <li>Embedding an iframe within the parent page, sharing the same origin.</li> <li>Loading scripts within the iframe that would typically be blocked by CSP if loaded directly onto the parent page.</li> <li>Exploiting the execution context of the parent page to carry out malicious actions through scripts within the iframe.</li> </ul> <h4>Please briefly explain who can exploit the vulnerability, and what they gain when doing so</h4> <p>The exploitation of CSP bypass via iframes can have significant repercussions:</p> <ul> <li><strong>XSS Attacks</strong>: Malicious scripts executed within the parent page&#39;s context can lead to data theft, session hijacking, or unauthorized access to sensitive information.</li> <li><strong>Content Injection</strong>: Attackers can inject malicious content into the parent page, such as phishing forms or deceptive advertisements, eroding user trust and damaging the application&#39;s integrity.</li> <li><strong>Data Exfiltration</strong>: By leveraging CSP bypass, attackers may exfiltrate sensitive user data accessible within the parent page to external servers, resulting in privacy violations and regulatory compliance issues.</li> </ul> <hr> <h3>The cause</h3> <h4>What version of Chrome have you found the security issue in?</h4> <p>123.0.6312.59 (Official Build) (x86_64)</p> <h4>Is the security issue related to a crash?</h4> <p>No</p> <h4>Choose the type of vulnerability</h4> <p>Sandbox Escape</p> <h4>How would you like to be publicly acknowledged for your report?</h4> <p>Aviv Keller (@RedYetiDev)</p>
