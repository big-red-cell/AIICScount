ch...@google.com： <h1>Steps to reproduce the problem</h1> <ol> <li>Open Chrome on macOS.</li> <li>Visit <a href="https://pwa-demo.github.io/install/" data-b-widget="url" data-b-original-href="https://pwa-demo.github.io/install/" data-b-redirected-href="https://www.google.com/url?q=https://pwa-demo.github.io/install/&amp;sa=D&amp;source=buganizer&amp;usg=AOvVaw1S5qJ6DomRCgSQsQflDoBP">https://pwa-demo.github.io/install/</a></li> <li>Click &quot;Install PWA.&quot;</li> <li>Click &quot;OK&quot; on the popup.</li> <li>If you click too fast, such as clicking twice, the upcoming install prompt will also be agreed to (this depends on your window size, of course).</li> <li>A malicious PWA is installed because you clicked too fast.</li> </ol> <h1>Problem Description</h1> <p>The installation banner prompt priority is lower than the alert box, which is not the case on Android Chrome. For example, instead of installing the PWA, the button could be any phishing button that the user can read. Additionally, the alert box has only one option, which is &quot;OK,&quot; and you can&#39;t close it. Therefore, if you click &quot;OK&quot; very quickly, it&#39;s very likely that you&#39;ll inadvertently click the upcoming installation banner. Based on my other posts, such as <a href="https://issues.chromium.org/issues/336589253" data-b-widget="issue-reference" data-b-issue-id="336589253">https://issues.chromium.org/issues/336589253</a>, the installed PWA could be from another origin.</p> <h1>Summary</h1> <p>Crafting installation banners with alert boxes can trick users into downloading PWAs.</p> <h1>Additional Data</h1> <p>Category: Security <br> Chrome Channel: Stable <br> Regression: N/A</p>

Later, phishing attempts could exploit this by sending notifications to users through this malicious PWA and continuing phishing (e.g., opening the malicious PWA could allow attackers to browse the internet and steal all website credentials.). <br><br>I acknowledge this isn&#39;t a perfect example, as there are some limitations, but I believe the problem lies in the inconsistency between the Desktop and Android versions. Additionally, the installation banner priority should be higher than other popups.
