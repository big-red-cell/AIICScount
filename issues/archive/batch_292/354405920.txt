<ul> <li>(HTML §8.1.4.2, <a href="https://html.spec.whatwg.org/#fetching-scripts" data-b-widget="url" data-b-original-href="https://html.spec.whatwg.org/#fetching-scripts" data-b-redirected-href="https://www.google.com/url?q=https://html.spec.whatwg.org/%23fetching-scripts&amp;sa=D&amp;source=buganizer&amp;usg=AOvVaw3SWX_oKDnRg6FP2E1dJzs_">https://html.spec.whatwg.org/#fetching-scripts</a>)</li> <li>receives a corsSetting</li> </ul> </li> <li>called from &quot;prepare the script element&quot; using the cors settings attribute <ul> <li>(§4.12.1.1, <a href="https://html.spec.whatwg.org/#script-processing-model" data-b-widget="url" data-b-original-href="https://html.spec.whatwg.org/#script-processing-model" data-b-redirected-href="https://www.google.com/url?q=https://html.spec.whatwg.org/%23script-processing-model&amp;sa=D&amp;source=buganizer&amp;usg=AOvVaw3TjpGf4K_DokO5nQpqQfxu">https://html.spec.whatwg.org/#script-processing-model</a>)</li> </ul> </li> <li>which defaults to no-cors if the attribute is missing (§2.5.4 <a href="https://html.spec.whatwg.org/#cors-settings-attributes" data-b-widget="url" data-b-original-href="https://html.spec.whatwg.org/#cors-settings-attributes" data-b-redirected-href="https://www.google.com/url?q=https://html.spec.whatwg.org/%23cors-settings-attributes&amp;sa=D&amp;source=buganizer&amp;usg=AOvVaw2kwSKsA7qvA9cjirhmKvRF">https://html.spec.whatwg.org/#cors-settings-attributes</a>)</li> </ul> </li> <li>The response gets blocked by CORB/ORB and raises a network error <ul> <li>&quot;HTTP fetch&quot;, step 6.4 (HTML Fetch PR 1442, <a href="https://whatpr.org/fetch/1442.html#http-fetch" data-b-widget="url" data-b-original-href="https://whatpr.org/fetch/1442.html#http-fetch" data-b-redirected-href="https://www.google.com/url?q=https://whatpr.org/fetch/1442.html%23http-fetch&amp;sa=D&amp;source=buganizer&amp;usg=AOvVaw1ofTFw85d5P04ybzuNJ9aX">https://whatpr.org/fetch/1442.html#http-fetch</a>)</li> </ul> </li> </ul>
