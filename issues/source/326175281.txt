fa...@sandbox.game： VULNERABILITY DETAILS<br><br>Summary: <br><br>Chrome allows JavaScript to be executed in bookmarks by default, which is currently exploited by active scam operations online.<br><br>Details: <br><br>An original report post can be found here: <a href="https://groups.google.com/a/chromium.org/g/chromium-discuss/c/IHWYS9xNWfE" target="_blank" rel="noopener noreferrer nofollow ugc" data-b-widget="url" data-b-original-href="https://groups.google.com/a/chromium.org/g/chromium-discuss/c/IHWYS9xNWfE" data-b-redirected-href="https://groups.google.com/a/chromium.org/g/chromium-discuss/c/IHWYS9xNWfE">https://groups.google.com/a/chromium.org/g/chromium-discuss/c/IHWYS9xNWfE</a><br><br>Our company has noticed an increased volume of phishing attempts involving the execution of Javascript in bookmarks.<br><br>Scammers trick users, through social engineering, to drag and drop a picture button into their bookmark browser area, then to open a tab on a service they are logged in and to click the bookmark button. fa...@sandbox.game： Hello,  We understand that this is a *feature*, not an XSS vulnerability, not even a vulnerability.  However, this is a dangerous feature, and we reported increasingly seeing it being used in successful scam and fraud operations.  The proposition is to disable Javascript execution in bookmarks by default, and allow the feature to be enabled should users want to, making Chrome a safer web browser to use for the future with its default configuration.  Would there be any blocker to doing such an improvement?
