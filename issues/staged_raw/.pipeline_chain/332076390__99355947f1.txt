Here are the simplified reproduction steps:

1: Create an HTML page containing `<a href="data:text/html,<script>alert(1)</script>" target="_blank">click here</a>`  
2: Open the HTML page in Chrome  
3: Click the link  
4: Reload the opened tab  

Note: This demonstrates the behavior where a data URL executes JavaScript after reload, which was reported as a potential security concern but was determined to be working as intended by the Chrome team. The key elements are the data URL in a link with target="_blank" and the reload action.
