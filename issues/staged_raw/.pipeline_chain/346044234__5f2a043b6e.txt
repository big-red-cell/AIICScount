Based on the discussion, this appears to be intended browser functionality rather than a vulnerability. However, here are the simplified reproduction steps as requested:

1: Open Microsoft Edge on a system where Google Chrome has saved passwords  
2: Navigate to Edge Settings > Passwords  
3: Click "Import Passwords"  
4: Select "Google Chrome" as the source  
5: Confirm the import action  

Note that these steps describe the legitimate password import feature between browsers, not a security vulnerability. The debate centered around whether this functionality should require additional authentication, but it's working as designed.
