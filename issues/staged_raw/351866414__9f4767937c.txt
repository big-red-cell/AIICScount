ch...@google.com： <h1>Steps to reproduce the problem</h1> <ol> <li>The user installs the extension.</li> <li>The extension declares a match pattern for content scripts.</li> <li>The extension could make arbitrary cross-origin requests to hosts the matching the patterns of the content script without &quot;host_permissions&quot;</li> </ol> <h1>Problem Description</h1> <p>Without host_permissions (even without any permission at all) the extension is able to send cross-origin requests. The problem is that the match patterns of the content script &quot;include&quot; the host permissions. Hosts for cross-origin requests and injecting content scripts should be separately maintained, as content scripts are intended to inject into pages that the user explicitly visits, while host permissions are to maintain the implicit requests that the extension could control.</p> <h1>Summary</h1> <p>Arbitrary cross-origin requests due to host permission bypassing using content script match patterns</p> <h1>Custom Questions</h1> <h4>Reporter credit:</h4> <p>Chaejin Lim (<a href="mailto:chaejin98@gmail.com" data-b-widget="url" data-b-original-href="mailto:chaejin98@gmail.com" data-b-redirected-href="mailto:chaejin98@gmail.com">chaejin98@gmail.com</a>)</p> <h1>Additional Data</h1> <p>Category: Security <br> Chrome Channel: Stable <br> Regression: Yes</p>
