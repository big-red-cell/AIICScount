Author: # Steps to reproduce the problem
1. Visit http://2:2@httpbin.org/basic-auth/2/2
2. Now from omnibox, copy the URL & paste in notepad, Notice that credentials are also getting copied. Perform the same in firefox, Note that credential part from url is not copied in firefox browser
3. Similarly when you click share url in android version also, the url is shared with credentials which is a huge risk.

# Problem Description
When user copies url from omnibox in desktop or shares url by clicking on share icon in android, HTTP Auth credentials present in URL is also getting copied.
The same doesn't happen with Firefox.

For example: In http://2:2@httpbin.org/basic-auth/2/2 , 2:2 is username & password present in URL this shouldn't be copied/shared.
