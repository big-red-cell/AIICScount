Security Bug<br>-------------------------<br><br>VULNERABILITY DETAILS<br>ResourceTiming entries are not generated for responses with 204, 205 status codes when loaded in an iframe. This allows malicious sites to infer whether a particular site responded with a 204 or 205 status code by loading the victim site in an iframe.<br><br>VERSION<br>Chrome Version: 126.0.6449.0 (Official Build) canary (64-bit) (cohort: Clang-64) <br>Operating System: Windows 11<br><br>REPRODUCTION CASE<br>1. Run a Python HTTP server by running `python -m http.server` in the same directory as the index.html file.<br>2. Install Flask `pip3 install flask` and run the app.py file using `python3 app.py` in a terminal.<br>3. Open <a href="https://www.google.com/url?q=http://localhost:8000/index.html&amp;sa=D&amp;source=buganizer&amp;usg=AOvVaw3teZqeXEET1WW4ZkYvPym0" target="_blank" rel="noopener noreferrer nofollow ugc" data-b-widget="url" data-b-original-href="http://localhost:8000/index.html" data-b-redirected-href="https://www.google.com/url?q=http://localhost:8000/index.html&amp;sa=D&amp;source=buganizer&amp;usg=AOvVaw3teZqeXEET1WW4ZkYvPym0">http://localhost:8000/index.html</a> in Chrome.<br>4. Open the DevTools Console.<br>See that <a href="https://www.google.com/url?q=http://localhost:5000/content&amp;sa=D&amp;source=buganizer&amp;usg=AOvVaw1S4f4-ETkqGIVlQSdziXAV" target="_blank" rel="noopener noreferrer nofollow ugc" data-b-widget="url" data-b-original-href="http://localhost:5000/content" data-b-redirected-href="https://www.google.com/url?q=http://localhost:5000/content&amp;sa=D&amp;source=buganizer&amp;usg=AOvVaw1S4f4-ETkqGIVlQSdziXAV">http://localhost:5000/content</a> should be correctly identified as not responding with a 204, 205 response status code, whereas <a href="https://www.google.com/url?q=http://localhost:5000/reset-content&amp;sa=D&amp;source=buganizer&amp;usg=AOvVaw3g3sNIk2MiBD-bkradzedT" target="_blank" rel="noopener noreferrer nofollow ugc" data-b-widget="url" data-b-original-href="http://localhost:5000/reset-content" data-b-redirected-href="https://www.google.com/url?q=http://localhost:5000/reset-content&amp;sa=D&amp;source=buganizer&amp;usg=AOvVaw3g3sNIk2MiBD-bkradzedT">http://localhost:5000/reset-content</a> and <a href="https://www.google.com/url?q=http://localhost:5000/no-content&amp;sa=D&amp;source=buganizer&amp;usg=AOvVaw2oQiEf-ZIOexne-iGCZwl4" target="_blank" rel="noopener noreferrer nofollow ugc" data-b-widget="url" data-b-original-href="http://localhost:5000/no-content" data-b-redirected-href="https://www.google.com/url?q=http://localhost:5000/no-content&amp;sa=D&amp;source=buganizer&amp;usg=AOvVaw2oQiEf-ZIOexne-iGCZwl4">http://localhost:5000/no-content</a> should be correctly identified as having a 204, 205 response status code.<br><br>CREDIT INFORMATION<br>Reporter credit: Shaheen Fazim
