<h1>Problem Description</h1>
<p>When the page loads, it automatically attempts to close the browser window using &quot;javascript:window.close(self);&quot; However, iThis vulnerability only affecting in Google Chrome Custom Tabs. On other platforms such as Mac and Windows, attempting to execute the same action would result in an error being logged in the browser console, rather than the window closing.</p>
