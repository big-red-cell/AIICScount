<h4>Sump</h4>
<p>When Chrome Is Installed And Used On MacOs, It Saves All Kind Of Files And User Generated Private Data On This Path</p>
<p><code>/Users/Username/Library/Application Support/Google/Chrome/*</code></p>
<p>This Above Path And Its Subdirectories Are Accessible By An Unsandboxed App
So If You Install My App On Your MacOs Then It Can Access User&#39;s All Chrome Profiles, Personal Stored Data, Cookies, Access Token And All Private And Confidential Info Without Any Consent From The User</p>
<p>I Told This Security Bug To Apple And Must Be fixed By It But Apple Thinks, Outsider Apps Should Protect Themselves With their Own Ways.</p>
<h4>StoR:</h4>
<p>This Security Bug Is Exploitable By An App So See The Attached Project. In The Project I Am Demonstrating The Access Ability Of The App To The Chrome&#39;s Cookies Files Without Any User Consent.</p>
<p>As Like Cookies File, Any Other File Also Can Be Accessed By My App But Cookies File Is Top Critical File In Reference Of User&#39;s Privacy And Confidential Perspective So This Is Best Data Here To Demonstrate</p>
<p>Just Open The Project On Xcode And Run It. If You Want To Test It On Another MacOs System, Reproduce The Local Copy Of App On Xcode And Run It On Chosen System.</p>
<p>Cookies May Be In Unreadable Form But A Simple Python Script Will Convert It To The Readable Format. Want The Script?</p>
<p>Most Data Stored In Those Folders Is In Readable Form So It Is Not A Big Issue</p>
<h4>Version</h4>
<p>Chrome Version:   125.0.6422.142</p>
<p>Operating System:  MacOS Sonoma 14.5 (23F79)</p>
<h4>Impact</h4>
<p>User&#39;s Confidential Data Can Be Accessed Unauthorizedly By An Unsandboxed App. Apps That Want Extra Privileges On System Are Developed As Unsandboxed Type, Chrome Itself Is A Type Of Unsandboxed App</p>
<p>So Many Popular And Useful Apps Are Not Available On App Store So They Are Downloaded From Internet And Usually They Are Unsandboxed Type, Apps Like Vpn, Other Browsers Like Firefox Are Normally Installed On The MacOs System By The User And These Are The Apps Which Can Access Chrome Users&#39; Data Directly</p>
