Security Bug<br>-------------------------<br><br>VULNERABILITY DETAILS<br>Using the proof-of-concept below, an attacker&#39;s website could spoof the victim&#39;s iOS Chrome browser to show a `tel: ` protocol bubble on a different trusted website, such as <a href="https://www.google.com/url?q=http://apple.com&amp;sa=D&amp;source=buganizer&amp;usg=AOvVaw0MLhs5jjklEaqMFcidxUg3" target="_blank" rel="noopener noreferrer nofollow ugc" data-b-widget="url" data-b-original-href="http://apple.com" data-b-redirected-href="https://www.google.com/url?q=http://apple.com&amp;sa=D&amp;source=buganizer&amp;usg=AOvVaw0MLhs5jjklEaqMFcidxUg3">apple.com</a>.<br><br>This can be exploited by scamming groups. When a victim clicks their link, the attacker&#39;s scam service number could appear on top of any trusted website, thus spoofing the browser and tricking the victim into calling them.<br><br>VERSION<br>- Chrome Version: 127.0.6533.77<br>- Operating System: iOS Version 17.5.1<br><br>REPRODUCTION CASE<br>1. Download the `poc.html` file and host it on an HTTP server.<br>2. Open the website on the iOS Chrome browser and click the button.<br>3. Observe that the telephone bubble with the attacker&#39;s phone number appears on top of the <a href="https://www.google.com/url?q=http://apple.com&amp;sa=D&amp;source=buganizer&amp;usg=AOvVaw0MLhs5jjklEaqMFcidxUg3" target="_blank" rel="noopener noreferrer nofollow ugc" data-b-widget="url" data-b-original-href="http://apple.com" data-b-redirected-href="https://www.google.com/url?q=http://apple.com&amp;sa=D&amp;source=buganizer&amp;usg=AOvVaw0MLhs5jjklEaqMFcidxUg3">apple.com</a> website.<br><br>CREDIT INFORMATION<br>Externally reported security bugs may appear in Chrome release notes.
