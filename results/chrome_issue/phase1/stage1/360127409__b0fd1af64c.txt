VULNERABILITY DETAILS

Please provide a brief explanation of the security issue.

```
A type casting failure in `src/objects/objects.cc, line 325` was reported in the form of a failure of DCHECK.
In the detected line of code, `value` is not `null` and cannot be converted to a `To` type (`JSReceiver`).

At this point, I am investigating the possibility that during the process of `JSReceiver::ToPrimitive` being called inside `ConvertToNumber`, the object was not converted to a primitive value and remained as a type that we did not expect.

I first identified this issue in `12.8.99-pgo`, but the PoC (PoC_0.js) provided by fuzzilli only showed an unusually long execution time, and the stack trace was unrecognizable, even though I built it with the symbols in d8.

Shortly thereafter, poc_1.js was detected on the same instance running `12.8.99-pgo`, and despite its relatively long length, I was able to reproduce the problem reliably with `--allow-natives-syntax`, and it also produced a stack trace with symbols.

I then tried to reproduce it on the head commit of the main branch using poc_1.js, which also reproduced reliably.

Since the first branch I identified was `12.8.99-pgo`, I'm pretty confident that this issue is already reported. 

However, if this issue was previously unrecognized, I believe it is a clear indication of type confusion and needs to be fixed sooner rather than later.
```
