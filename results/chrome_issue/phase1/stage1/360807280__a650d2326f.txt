<h3>The problem</h3>
<h4>Please describe the technical details of the vulnerability</h4>
<p>A vulnerability exists in Chrome for macOS that allows a Facetime open dialog to be displayed over a different tab, potentially misleading the user into believing that the dialog was opened by the visible tab, rather than the actual origin that triggered it.</p>
<p>Since the only origin information presented to the user at this time is for &quot;amazon.com&quot; (or whichever site is currently displayed in the tab), the user may be tricked into thinking that the currently visible site requested Facetime.</p>
