<h1>Problem Description</h1>
<p>If a page on a subdomain (or domain) frames an other iframe that have another subdomain of the same top domain it will not have access to the iframes location by SOP. But by changing the iframes location to about:blank the iframes (second level iframe ) window will now be accessible from the top window. And the window.navigation.entities() will still contain all navigation entities from the previously framed subdomain</p>
<p>This is a similar report to (bypass of ) CVE-2022-4908 where researcher have used navigation.entry() method to leak the staled urls from the history using navigation API.
Google Team mitigated the risk not allowing iframes to not leak any Cross-Document from the single framed pages but when an attacker uses double frame the page now it is accessible to their parent iframe very similarly to  <a href="https://issues.chromium.org/issues/40060755#comment41" data-b-widget="issue-reference" data-b-issue-id="40060755" data-b-comment-number="41">https://issues.chromium.org/issues/40060755#comment41</a></p>
