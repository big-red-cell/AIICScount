VULNERABILITY DETAILS
In certain circumstances, there is a possible scenario where CORS/CSP policies are being ignored by Chrome, allowing malicious actor to steal personal data from another unrelated web resource.

VERSION
Chrome Version: 127.0.6533.120 stable
Operating System: macOS Version 14.6.1 (Build 23G93)

REPRODUCTION CASE
Following reproduction scenario shows how vulnerability is present in Chrome, but non-reproducible in other browser such as Safari or Firefox. 
1. Go to https://yoomoney.ru/yooid/signup/step/phone and sign up for an account — no need to get verified, just an anonymous account with no KYC done is sufficient (I'm using this service as a demo);
2. Once account created, deploy attached `index.html` file on any publicly-accessible domain with HTTPS enabled. Let's assume you have it deployed on `https://vulerability-example.com`;
3. While being signed in on yoomoney.ru, open separate tab with `https://vulerability-example.com` and click `Fetch`.
4. CORS-violating XHR-request fetches personal data from `yoomoney.ru` ignoring policies and supplying it with cookies from 3rd-party domain.
5. Observe stolen data.
