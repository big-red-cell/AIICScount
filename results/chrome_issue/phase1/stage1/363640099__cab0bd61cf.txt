Author: ma...@chromium.org
<p>I’m not sure I understand what the perceived vulnerability is here or how an attacker would exploit it.</p>
<p>The browser process and WebKit processes on iOS are subject to sandbox policies. These policies are defined by the operating system and limit exactly which parts of the file system third party applications can access.</p>
<p>/etc/passwd, used in the steps to reproduce, is explicitly permitted by the sandbox policies used for third party applications and for WebKit processes. If an attacker had remote code execution they could access this file directly.</p>
