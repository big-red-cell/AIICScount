The vulnerability arises because this script allows the iframe to trigger the opening of a PiP window by sending a message without additional validation. In other words, if the iframe sends the message &#39;openPip&#39;, the script will open a PiP window. This can be exploited by an attacker to open a PiP window from a subframe, potentially bypassing security restrictions.<br><br>    - documentPictureInPicture.requestWindow(...): This function is used to open a PiP window. The vulnerability occurs because this script allows the PiP window to be opened without checking if the request is coming from the topmost frame or not. An attacker can exploit this to open a PiP window from a subframe.<br><br>Script in anu.html: Sends a message from the iframe to the parent to trigger the PiP window, which is crucial for the attack.<br>Explanation:<br><br>    - window.parent.postMessage(&#39;openPip&#39;, &#39;*&#39;): This script sends the message &#39;openPip&#39; to the parent window when the button is clicked. The vulnerability is that a subframe can send this message to the parent window without any additional validation. This allows the subframe to trigger actions in the parent window, such as opening a PiP window, which should only be allowed from the topmost frame.<br><br><br>Summary<br><br>The security issue arises because:<br><br>   -  In 3.html: The script receives a message from the iframe and opens a PiP window without verifying if the request comes from the topmost frame.<br>   -  In anu.html: The script allows the subframe to send a message to the parent window to open a PiP window, which can be exploited by a subframe from a different domain.<br><br>The core problem is the lack of control and validation in the communication between the iframe and the parent window, allowing the subframe to exploit functions that should be restricted to the topmost frame only.<br><br>Im send update file 3.html and anu.html<br>and can test update in : <a href="https://www.google.com/url?q=https://getbounty.online/3.html&amp;sa=D&amp;source=buganizer&amp;usg=AOvVaw1ShyWsmKNiP85Yj5wYzN0H" target="_blank" rel="noopener noreferrer nofollow ugc" data-b-widget="url" data-b-original-href="https://getbounty.online/3.html" data-b-redirected-href="https://www.google.com/url?q=https://getbounty.online/3.html&amp;sa=D&amp;source=buganizer&amp;usg=AOvVaw1ShyWsmKNiP85Yj5wYzN0H">https://getbounty.online/3.html</a><br><br>Ref : <a href="https://www.google.com/url?q=https://issues.chromium.org/issues/40063068&amp;sa=D&amp;source=buganizer&amp;usg=AOvVaw3XQ-NQph4xMVsBp3qTcqQP" target="_blank" rel="noopener noreferrer nofollow ugc" data-b-widget="url" data-b-original-href="https://issues.chromium.org/issues/40063068" data-b-redirected-href="https://www.google.com/url?q=https://issues.chromium.org/issues/40063068&amp;sa=D&amp;source=buganizer&amp;usg=AOvVaw3XQ-NQph4xMVsBp3qTcqQP">https://issues.chromium.org/issues/40063068</a><br><br>Thanks
