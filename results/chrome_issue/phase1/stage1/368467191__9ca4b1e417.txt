If you blocked <a href="https://www.google.com/url?q=http://example.com/abc&amp;sa=D&amp;source=buganizer&amp;usg=AOvVaw21hVFVRy-1WjScKljl4zNG" target="_blank" rel="noopener noreferrer nofollow ugc" data-b-widget="url" data-b-original-href="http://example.com/abc" data-b-redirected-href="https://www.google.com/url?q=http://example.com/abc&amp;sa=D&amp;source=buganizer&amp;usg=AOvVaw21hVFVRy-1WjScKljl4zNG">example.com/abc</a>, then <a href="https://www.google.com/url?q=http://example.com&amp;sa=D&amp;source=buganizer&amp;usg=AOvVaw2vKt98IJgycdV1jQk_Xbaj" target="_blank" rel="noopener noreferrer nofollow ugc" data-b-widget="url" data-b-original-href="http://example.com" data-b-redirected-href="https://www.google.com/url?q=http://example.com&amp;sa=D&amp;source=buganizer&amp;usg=AOvVaw2vKt98IJgycdV1jQk_Xbaj">example.com</a> could still load it using XMLHTTPRequest.
