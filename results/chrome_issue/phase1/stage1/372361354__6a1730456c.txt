It looks like Windows made more than just some size changes to the Share dialog, they brought it into alignment with other system UI like the print dialog. Most notably for this conversation - they made it modal and no longer light-dismiss.<br><br>The user can now move it to see any obscured pixels they would like to see, and if they would like to cancel the operation they now must do it explicitly from within the Share dialog. Though Windows does mostly block the user from going back to the calling window until the Share dialog has been dismissed, the dialog is independent system UI and will keep running even if the calling app is killed/crashed.<br><br>Given all this, it feels like this might not be a security issue. The user has been given more control, and the experience should be more predictable for the user now that it better aligns with other similar system experiences on Windows.
