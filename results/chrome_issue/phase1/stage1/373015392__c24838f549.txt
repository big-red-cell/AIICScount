VULNERABILITY DETAILS<br><br>Handling of navigation and redirection triggered by the beforeunload event. This vulnerability allows an attacker to prevent users from returning to the previous page and redirect them to a phising site without their knowledge.<br><br>beforeunload event signaling to the browser that the user is attempting to leave page.After alert is displayed, the user will be redirected to a different site. However, the actual navigation is handled with document.open(), which replaces current content and does not save navigation history in browser.<br>When users are redirected, they cannot return to their previous site using back button in the browser, thereby increasing the risk of phishing.<br><br>VERSION<br><br>OS : macOs Monterey<br>Canary : Version 131.0.6774.0 (Official Build) canary (x86_64)<br><br>REPRODUCTION CASE<br><br>1.
