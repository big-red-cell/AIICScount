<h1>Problem Description</h1>
<p>Hi team, I found Universal XSS on chrome browser using ios device which when attacker sends modified google.com link attacker can execute javascript code on victim&#39;s browser. This happens when the victim clicks on the modified link and uses the “Search suggestion” feature (Left up arrow) which can cause the execution of malicious javascript code on every domain visited by the victim. The payload will also be stored for a long time in the victim&#39;s browser. I have previously encountered similar cases on Microsoft Edge and Opera (For Opera users only need to press the search suggestion bar without clicking the left arrow up).</p>
<h1>Summary</h1>
<p>Universal XSS on chrome ios via search bar suggestion</p>
