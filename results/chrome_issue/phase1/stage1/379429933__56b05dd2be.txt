<p>[Security shepherd] Navigating to a different page by clicking on a link triggers the <code>onblur</code> handler, which redirects to an intent. The intent navigation is allowed. I think this is working as intended, as the navigation has a user gesture and happens on a page that is still active. See FAQ [1] and intent navigation docs [2].</p>
