### The problem


#### Please describe the technical details of the vulnerability

Open Redirection Vulnerability Report
Report Overview
Report Date: 17-11-2024
Reported By: DEEPAK JINDAL
Target Application: GOOGLE CHROME BROWSER
Version: 131.0.6778.70 (Official Build) (64-bit) (cohort: Stable)
Severity Level: HIGH
Vulnerability Description
An Open Redirection vulnerability allows an attacker to redirect users from a trusted site to a malicious site by manipulating URL parameters. This can lead to phishing attacks, where users may unknowingly provide sensitive information to an attacker-controlled site.
POC
The below is the POC Attached link:
https://drive.google.com/drive/folders/1PSlE6i-VVEdpD-hsU_7o4BvpvYP1jCdF?usp=sharing



#### Please briefly explain who can exploit the vulnerability, and what they gain when doing so

Vulnerability Details
•	Vulnerable URL:  Google Chrome Browser and Chrome browser URL.
•	Payload: &&result_url=@evil.com 
•	Example of Exploit:
A malicious threat actor visit the chrome browser and then enters the below payload. 
•	Payload: &&result_url=@evil.com
The application does not properly validate the url parameter, allowing redirection to an external site as shown in the POC attached. 
Impact
The impact of this vulnerability can lead to:
1.	Phishing Attacks: Attackers can trick users into providing sensitive information.
2.	Loss of Trust: Users may lose trust in the application if they are redirected to malicious sites.
3.	Brand Reputation Damage: The organization’s reputation may be harmed due to association with malicious activities.
