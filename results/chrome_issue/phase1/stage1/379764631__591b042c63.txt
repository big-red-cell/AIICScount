<p><strong>VULNERABILITY DETAILS</strong></p>
<p>The address bar JavaScript filter can be bypassed by following steps to successfully execute javascript code on any websites:
1.Copy the following link to your clipboard: javascript:alert(document.cookie)
2.Visit any website, such as gmail.google.com
3.Click the address bar, then click &quot;Text you copied&quot; and the javascript code will be executed on gmail.google.com.</p>
