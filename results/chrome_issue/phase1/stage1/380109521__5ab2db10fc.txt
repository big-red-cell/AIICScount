<p>I do not see any demonstration of a security issue in this PoC. The requirement for CORS when using CSS shapes from images is because the site using the shape can learn information about the image from its use, so the server providing the image needs to opt into sharing the resource. In the provided PoC, the shape and the content using the shape come from the same source.</p>
<p>I am not commenting on whether Chrome is internally generating or processing the correct values for a Access-Control-Allow-Origin header (there is no network request, so it doesn&#39;t actually exist). If there is an issue with that, based on the information provided, it would be a functional bug not a security bug.</p>
