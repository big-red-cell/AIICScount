<h1>Problem Description</h1>
<p>I have constructed a certificate chain consisting of [end, inner, root] and successfully added the inner certificate to the intermediate certificate store and the root certificate to the root certificate store. Additionally, I forcibly added a self-signed root certificate named X.der to the system&#39;s intermediate CA store using the command certutil -addstore -f CA X.der.</p>
<p>However, while Firefox successfully verifies the correct certificate chain as [end, inner, root], Chrome incorrectly constructs the certificate chain as [end, X, inner, root]. This indicates that Chrome is failing to detect that certificate X is not a valid intermediate CA, thus allowing an invalid chain to be formed.</p>
<h1>Summary</h1>
<p>Chrome Incorrectly Treats Root Certificate as Intermediate CA in Certificate Chain</p>
