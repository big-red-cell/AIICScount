<h1>Problem Description</h1>
<p>When a user clicks on the attacker&#39;s page in Android Chrome it is possible to call payment request and at the same time request the page to enter Fullscreen. When a user clicks on Continue for the payments and User tries to exit the Fullscreen and User touch on Back button The Fullscreen Chrome does not exit or cancel the Fullscreen mode</p>
<p>It seems that when both are called at the same time, and Fullscreen can&#39;t be cancelled due to payment request dialog<br>
the payment request Dialog is preventing the Fullscreen to exit</p>
<p>**Fixing Suggestion: **</p>
<ul>
<li>When payment request Dialog shows it has to cancel the Fullscreen mode</li>
</ul>
