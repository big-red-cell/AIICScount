<h1>Problem Description</h1>
<p>Potential data leakage.  If different OPFS and requestFileSystem share the same storage layer, there could be unintended access to files created in OPFS by using the deprecated requestFileSystem API, which is not ideal for privacy or security.</p>

<p>[security triage] Your example uses the same origin for both the OPFS and requestFileSystem calls, which is not a security vulnerability. There is no problem with a site accessing its own files in OPFS. You mention &quot;If different OPFS and requestFileSystem share the same storage layer...&quot;, and I agree that if you could demonstrate access to a different origin&#39;s OPFS through requestFileSystem that would be a security vulnerability.</p>
