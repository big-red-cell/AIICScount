Author: cl...@google.com
<p>I don&#39;t think this is a bug we need to fix. Iframes are sending load notifications, per spec. At the same time, we have no way to limit which files are loaded by a file URL. I don&#39;t see how we could come up with a meaningful way of doing so since we do not have access to origins for file URLs.</p>
<p>Since the report requires downloading a file and opening it in Chrome in the first place, I don&#39;t think there is real risk for the user (or more accurately, if you can get a user to download a file and open it, you can do probably a lot worse). I will mark this as won&#39;t fix.</p>
