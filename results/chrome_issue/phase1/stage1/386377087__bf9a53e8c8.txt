<h3>The problem</h3>
<h4>Please describe the technical details of the vulnerability</h4>
<p><strong>Affected Product</strong>: Chrome Browser</p>
<p><strong>Platform</strong>: Chrome on Windows, macOS, Linux, Android (Applicable for all platforms where Chrome&#39;s autofill is supported)</p>
<p><strong>Severity Level</strong>: High</p>
<p><strong>Bug Type</strong>: Information Disclosure / Privacy Impact</p>
<p>Chrome&#39;s Password Manager, responsible for autofilling saved credentials, fails to properly handle security after user sign-out. Upon signing out from a Google account or Chrome, the password manager continues to autofill credentials in some instances, leaving sensitive user information exposed. This unintended behavior is due to insufficient sanitization of saved passwords in the autofill cache, which remains accessible even after the user has signed out, leading to the possibility of unauthorized information disclosure.</p>
<p>This issue could potentially lead to an attacker gaining access to the user&#39;s saved passwords if the browser is left running after sign-out, or in cases where shared devices are used without fully closing the browser session.</p>
<p><strong>Steps to Reproduce:</strong></p>
<ol>
<li>Sign in to a Google account in Chrome and enable the Password Manager with autofill functionality.</li>
<li>Save a password for a website using Chrome&#39;s Password Manager.</li>
<li>Sign out of the Google account, but leave the browser session open.</li>
<li>Attempt to use the autofill feature to fill in a password field on a website.</li>
<li>Observe that autofill occurs despite the sign-out.</li>
</ol>
<p><strong>Impact:</strong></p>
<ol>
<li>Confidentiality Risk: Autofilled credentials remain accessible after sign-out, enabling unauthorized access to stored sensitive information such as passwords and personal data.</li>
</ol>
<p>2)Privacy Breach: In shared or public environments, a malicious actor can exploit this flaw to gain unauthorized access to the user&#39;s saved credentials, including those for sensitive services (e.g., banking, email, social media).</p>
<p><strong>Suggested Mitigation:</strong></p>
<ol>
<li>
<p>Invalidate Autofill Data on Sign-Out: Chrome should ensure that all autofill data stored in the Password Manager is invalidated upon user sign-out. This would prevent any unauthorized access to saved credentials.</p>
</li>
<li>
<p>Implement Session Expiration for Autofill Data: Introduce a secure session expiration mechanism to ensure that autofill data is not accessible after the session has expired.</p>
</li>
<li>
<p>Enhanced User Notification: Provide clear feedback to users when they sign out of their Google account, confirming that saved passwords and autofill data are no longer accessible.</p>
</li>
</ol>
<h4>Please briefly explain who can exploit the vulnerability, and what they gain when doing so</h4>
<p><strong>Who can exploit the vulnerability?</strong></p>
<ol>
<li>
<p>Malicious Users with Physical Access: Any user who has access to the device where Chrome is running can exploit this issue, especially in shared or public environments (e.g., libraries, coffee shops, public computers).</p>
</li>
<li>
<p>Attackers on Unsecured Machines: If a user leaves their browser open after signing out, an attacker could access the system and trigger the autofill feature to retrieve saved credentials.</p>
</li>
<li>
<p>Insider Threats: A trusted individual with access to the device could exploit this vulnerability for malicious purposes.</p>
</li>
</ol>
<p><strong>What they gain:</strong></p>
<ol>
<li>
<p>Sensitive Credentials: Attackers can retrieve usernames, passwords, and other sensitive information saved in Chrome&#39;s Password Manager, which could include credentials for email, social media, banking, or other personal accounts.</p>
</li>
<li>
<p>Unauthorized Access to User Accounts: Using the extracted credentials, attackers can access the victim’s online accounts, potentially leading to identity theft, financial loss, or exposure of private data.</p>
</li>
<li>
<p>Privacy Breach: The attacker may gain access to personal or confidential information saved in the browser (e.g., payment details, address, contact info) that could be used for further exploitation.</p>
</li>
</ol>
