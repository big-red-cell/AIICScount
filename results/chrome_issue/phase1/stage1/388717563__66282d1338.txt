# Problem Description
Spoofed File Example:
`hacked.php          www.google.com`
The spaces will be converted to %20, and the file origin will appear as `hacked.php%20%20%20%20%20%20%20%20%20%20www.google.com`. If we can place the @ character accurately, it can make www.google.com appear on a new line in the download origin. This will make the file seem like it is coming from google.com.

# Additional Comments
Note: if you want to try this bug locally without my PoC page on Github, you must create your own `hacked.php` file, based on my calculations, the optimal number of spaces for spoofing on macOS is 10.
