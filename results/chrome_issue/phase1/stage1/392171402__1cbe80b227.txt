<h1>Problem Description</h1>
<p>A bug in chrome Browser for macOS allows an attacker to spoof the omnibox (address bar) by opening a new tab with a crafted URL containing an about:blank fragment (about:blank#very-super-duper-long-subdomain.paypal.com). Instead of displaying the full URL in the omnibox, Brave only shows about:blank, which could mislead users into believing they are interacting with a blank or safe page. This can potentially be exploited for phishing or social engineering attacks.</p>
<p>Expected Result:
The omnibox should display the full URL about:blank#very-super-duper-long-subdomain.paypal.com to prevent potential spoofing attempts.</p>
<p>Actual Result:
The omnibox only displays about:blank, hiding the fragment part (#very-super-duper-long-subdomain.paypal.com) of the URL. This can mislead users into believing the page is genuinely blank.</p>
<h1>Summary</h1>
<p>Omnibox Spoofing via about:blank with Fragment on chrome macOS</p>
