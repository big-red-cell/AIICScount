#### Vulnerability Description
##### [Regular Expression Denial of Service (ReDoS) affecting koa](http://vulnstore/#advisories&expand=true&q=publisher:SNYK+reference:JS-KOA-8720152)

[koa](https://www.npmjs.org/package/koa) is a Koa web app framework

Affected versions of this package are vulnerable to Regular Expression Denial of Service (ReDoS) via the parsing of `X-Forwarded-Proto` and `X-Forwarded-Host` HTTP headers.

Related CVE(s):
- [CVE-2025-25200](https://nvd.nist.gov/vuln/detail/CVE-2025-25200)

     - Dependency path to affected package\*:
         - v8-tools@1.0.0 &gt; local-web-server@4.2.1 &gt; lws@3.1.0 &gt; koa@2.13.1

package paths.

#### Remediation Guidance
##### [Regular Expression Denial of Service (ReDoS) affecting koa](http://vulnstore/#advisories&expand=true&q=publisher:SNYK+reference:JS-KOA-8720152)
