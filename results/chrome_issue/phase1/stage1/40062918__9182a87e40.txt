<p><strong>Problem Description:</strong><br>
According to the chromium file types policy documentation (<a href="https://source.chromium.org/chromium/chromium/src/+/main:components/safe_browsing/core/resources/download_file_types.asciipb;drc=af17ad3f07c1d8a24381eb7669bec0c2ffb86521" data-b-widget="url" data-b-original-href="https://source.chromium.org/chromium/chromium/src/+/main:components/safe_browsing/core/resources/download_file_types.asciipb;drc=af17ad3f07c1d8a24381eb7669bec0c2ffb86521" data-b-redirected-href="https://www.google.com/url?q=https://source.chromium.org/chromium/chromium/src/%2B/main:components/safe_browsing/core/resources/download_file_types.asciipb;drc%3Daf17ad3f07c1d8a24381eb7669bec0c2ffb86521&amp;sa=D&amp;source=buganizer&amp;usg=AOvVaw3u1_AtltxY6DQ9jDzAW1ol">https://source.chromium.org/chromium/chromium/src/+/main:components/safe_browsing/core/resources/download_file_types.asciipb;drc=af17ad3f07c1d8a24381eb7669bec0c2ffb86521</a>), there are several extesnions for RAR are included as gesture files which are inherently benign, but may contain dangerous files.<br>
