<p><strong>VULNERABILITY DETAILS</strong></p>
<p>Microsoft Publisher (.pub file extension) malicious documents</p>
<p>Upon opening the .pub file, the victim is prompted to “Enable Macros” (earlier versions of Microsoft Publisher may display instructions to also “Enable Editing” and “Enable Content,”</p>
<p>Microsoft Publisher (.pub) attachments with malicious macros, URLs linking to .pub files with macros, or containing URLs that download dangerous JavaScript files.</p>
<p>The file used in this campaign was aimed at infecting the victim.<br>
Publisher is still installed on many computers because the default setup of Office 365 proposes it by default:</p>
<p>Add a Harmful Warning to .pub file Extension.</p>
<p>There is No (.pub) file Extension in Chrome Safe Browsing List:</p>
<p>safe_browsing/content/resources/download_file_types.asciipb</p>
<p>To Add:</p>
<p>file_types {<br>
extension: &quot;pub&quot;<br>
ping_setting: FULL_PING<br>
platform_settings {<br>
platform: PLATFORM_TYPE_WINDOWS<br>
danger_level: ALLOW_ON_USER_GESTURE<br>
auto_open_hint: DISALLOW_AUTO_OPEN<br>
}<br>
}</p>
<p><strong>VERSION</strong></p>
<p>Chrome Version: [116.0.5845.188 (Official Build)] + [stable]<br>
Operating System: [Windows 10]</p>
<p><strong>REPRODUCTION CASE</strong></p>
<ol>
<li>Create .pub Extension File</li>
<li>Drag to Chrome Browser (Or) Host in Your Server &amp; Download from Chrome</li>
</ol>
