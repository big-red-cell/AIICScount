<p>Thanks for the report.</p>
<p>We wouldn&#39;t consider this a tapjacking bug. The context menu does show over the permission prompt, but the user has to manually dismiss it or select one of the buttons. There isn&#39;t a way for the page to dismiss the context menu right before the user taps, or induce the user to continue tapping in the same spot even as the context menu is going away. That would be unusual user behaviour beyond the control of the site.</p>
