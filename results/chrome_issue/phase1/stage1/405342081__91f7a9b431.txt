<h3>Report description</h3>
<p>Google Chrome does not clear localStorage properly. When a value is removed from localStorage while it seems to be removed in chrome&#39;s interface in the localStorage files themselves it persists.</p>

<h3>The problem</h3>
<h4>Please describe the technical details of the vulnerability</h4>
<p>Essentially, when a value is removed from chrome&#39;s localStorage(websites, extensions) while it seems to have been removed on chrome&#39;s developer interface the value persists in the AppData localStorage files themselves and it can be extracted. This could lead to a large amount of issues involving stealer malware and other things.
I have attached a short video demonstrating it.</p>
<h4>Please briefly explain who can exploit the vulnerability, and what they gain when doing so</h4>
<p>Stealer Malware: A website may store sensitive information in localStorage and clear it, but since it persists in the localStorage files themselves if an attacker steals the files(with stealer malware for example) they can see the sensitive information.</p>

<h3>The cause</h3>
<h4>What version of Chrome have you found the security issue in?</h4>
