<h3>The problem</h3>
<h4>Please describe the technical details of the vulnerability</h4>
<p>Data URI XSS is a type of Cross-Site Scripting (XSS) vulnerability that occurs when a website allows the embedding of JavaScript code within data: URIs. This happens when the href attribute of an anchor (<span>&lt;a&gt;</span>) tag, or any other URL-related attribute, contains a data: URI that holds executable JavaScript code. If the application does not properly sanitize or validate user inputs or generated content, an attacker can inject a malicious data: URI that, when clicked, executes arbitrary JavaScript in the context of the victim&#39;s browser.</p>

<p>The impact of Data URI XSS can lead to the execution of malicious JavaScript in a victim&#39;s browser, enabling session hijacking, data theft, or unauthorized actions. In severe cases, it can allow an attacker to take full control over a victim&#39;s session.</p>
