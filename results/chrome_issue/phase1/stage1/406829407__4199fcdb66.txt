<p>Hi, thanks for reporting. This is not a vulnerability.</p>
<p>The IsPrefixedAPI function relies on an assumption (enforced by DCHECK) that its inputs are ordered, and it&#39;s used in a context where that assumption always holds true.</p>
<p>I have checked your example but the example doesn&#39;t match how the function is intended to be used. The example you provided root_api = &quot;apple&quot; and api = &quot;applf&quot; is not a valid scenario, as &quot;applf&quot; is not a prefix of &quot;apple&quot;. The function is intended to be used with strings where api is a prefix of root_api followed by a dot, such as api = &quot;app.runtime&quot; and root_api = &quot;app&quot;. The code&#39;s use within the class adheres to this design.</p>
<p>I am closing this as a won&#39;t fix. Thanks again for reporting.</p>
