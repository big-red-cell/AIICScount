<h1>Problem Description</h1>
<p>The Chromium download dialog fails to display the full filename including the file extension in some scenarios, which can mislead users about the true nature of a downloaded file. This can be exploited for file type spoofing (e.g., file appearing as a .php), increasing the risk of social engineering attacks and unintended execution of malicious content.</p>
<p>Observed Behavior:
The UI download dialog may omit or truncate the actual file extension (.php), displaying only invoice, misleading the user.
Expected Behavior:
The UI should always display the full and actual filename including the extension, especially for executable or potentially dangerous file types.</p>
