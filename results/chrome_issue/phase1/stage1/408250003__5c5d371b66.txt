<h1>Problem Description</h1>
<p><strong>Affected Chrome Version:</strong></p>
<ul>
<li><strong>Chrome Version:</strong> 135.0.7049.41 (Official Build) (64-bit)</li>
<li><strong>Operating System:</strong> Windows 11</li>
</ul>
<p><strong>Vulnerability Description:</strong><br>
A vulnerability has been identified related to the use of <strong>Unicode emoji characters</strong> in cookie values, which can lead to <strong>permanent denial-of-service (DoS)</strong> attacks on many websites. Using certain Unicode emoji characters in cookie values, such as <strong>🍪, 🍦, and 🍩</strong>, can disrupt cookie processing, causing websites to malfunction and display error messages like &quot;something went wrong&quot; or other similar errors.</p>
<p><strong>Expected Behavior:</strong><br>
After running the code and reloading the page, the website should function normally, displaying content without errors or disruptions.</p>
<p><strong>Actual Behavior:</strong><br>
The website fails to process cookies containing Unicode emoji characters (🍪🍦🍩), causing the website to <strong>malfunction</strong>. The error messages that appear include &quot;something went wrong&quot; on sites like Facebook or Netflix.</p>
<p><strong>Risk:</strong><br>
This vulnerability can be exploited by an attacker to <strong>cause permanent damage to a website</strong> by setting cookies with broken Unicode emoji characters. Additionally, <strong>cross-origin cookies</strong> can affect the main site and its subdomains, which increases the potential impact of the vulnerability.</p>
<h1>Summary</h1>
<p>Unicode Emoji Cookie Values Can Cause Permanent Denial-of-Service (DoS) Attacks on Websites</p>
