<h1>Steps to reproduce the problem</h1>
<ol>
<li>In a web page, launch a new window.</li>
<li>Generate an inline download of an Excel or similar file (.xls) that can have malicious content.</li>
<li>The file is downloaded to the Downloads folder without the user being notified that a download happened.  The notification happens in the main window, not in the new window that actually initiated the download.  This does not happen in the main window because the notification happens.</li>
</ol>
<h1>Problem Description</h1>
<p>Vulnerability Details
In a recent update to Google Chrome (within the past month it seems), when a new window is opened, no components such as the taskbar are rendered, and downloads that are initiated do not ask for confirmation, and no notification is given to the end user that a download happened.  A new window can be opened that is large enough to cover the main window.  This prevents the user from seeing the main window.  Previously, when a download happened, the user would be notified.  In a recent update, the user is no longer notified.  Instead, it happens in the background.</p>
<p>If the notification happened (like it did previously and currently happens in the main window where the user cannot see it), then the user would immediately know something suspicious has happened.  However, now, due to this update, the user does not know.  And, they may visit their Downloads folder, and they will discover a new file.  By opening the new file, they will unintentionally be launching a file that can contain malicious code.  If the user was visiting a dangerous website, they would be more likely to be on guard, but they are never notified since the recent update, especially if the new window behavior covers the main window.</p>
<h1>Additional Comments</h1>
<p>I am including a screenshot of the prior behavior.  Without this notification, files can be sent to the Downloads folder of users without them even realizing it.</p>

<p>Chrome Allows Downloads of Malicious Files without User Notification</p>
