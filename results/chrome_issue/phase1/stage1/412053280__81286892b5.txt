<h3>The problem</h3>
<h4>Please describe the technical details of the vulnerability</h4>
<p>Vulnerability Information :  Description: Content spoofing, also referred to as content injection, &quot;arbitrary text injection&quot; or virtual defacement, is an attack targeting a user made possible by an injection vulnerability in a web application. When an application does not properly handle user-supplied data, an attacker can supply content to a web application, typically via a parameter value, that is reflected back to the user. This presents the user with a modified page under the context of the trusted domain.
Name of Vulnerability  : Text Injection
