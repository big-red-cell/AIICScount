<p>DevTools snippets don&#39;t have warnings for drag and drop on new/guest profile</p>

<hr>
<h3>The problem</h3>
<h4>Please describe the technical details of the vulnerability</h4>
<p>DevTools on guest/fresh profiles shows warnings on features to mitigate running malicious scripts from, for example:</p>
<ul>
<li>pasting or drag and drop scripts into the console</li>
<li>pasting scripts into Sources &gt; Snippets</li>
<li>importing Recorder files</li>
</ul>
<p>From the list above, drag and drop into Sources &gt; Snippets is not protected by a warning dialog.</p>
<p>The demo video demonstrates the current behavior on a guest profile.</p>
<p>Reproduction steps:</p>
<ol>
<li>Add a new Chrome profile or enter guest mode.</li>
<li>Find example JavaScript code online, then open DevTools &gt; Sources &gt; Snippets &gt; New snippet.</li>
<li>Select and drag and drop the script into the snippet editor.</li>
<li>Observe that no warning dialog appears (you can compare this to dragging and dropping into the Console instead).</li>
</ol>
<h4>Impact analysis – Please briefly explain who can exploit the vulnerability, and what they gain when doing so</h4>
<p>Who can exploit:</p>
<p>Attackers who share obfuscated, minified, or generally hard-to-read code, targeting individuals less knowledgeable about JavaScript or who do not care enough to review the code themselves.</p>
<p>What they gain:</p>
<p>The ability to run malicious scripts by taking advantage of the victim&#39;s unawareness or lack of diligence.</p>
