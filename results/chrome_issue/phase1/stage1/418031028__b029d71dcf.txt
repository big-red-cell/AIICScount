<br><br>-------------------------<br><br>VULNERABILITY DETAILS<br>A browser behaviour flaw has been identified where a crafted URL with a url fragment misleading path causes the browser to download a malicious file, while the URL appears to reference a benign file (e.g., a .pdf, jpg). This creates a significant risk of user deception, especially when the browser interface fails to alert the user about mismatches between the URL path, file extension, and actual file type being downloaded. This would create more realistic attack if adversary using google drive to deceive user to download malicious files<br><br>VERSION<br>Chrome Version: latest<br>Operating System: MacOS<br><br>REPRODUCTION CASE<br>1.craft url like <a href="https://www.google.com/url?q=https://example.com/payload.dmg%23/ABCDFGJTUEJ/files/download/payload.jpg&amp;sa=D&amp;source=buganizer&amp;usg=AOvVaw0E7Qwq-Llm4epR2CG_d_-N" target="_blank" rel="noopener noreferrer nofollow ugc" data-b-widget="url" data-b-original-href="https://example.com/payload.dmg#/ABCDFGJTUEJ/files/download/payload.jpg" data-b-redirected-href="https://www.google.com/url?q=https://example.com/payload.dmg%23/ABCDFGJTUEJ/files/download/payload.jpg&amp;sa=D&amp;source=buganizer&amp;usg=AOvVaw0E7Qwq-Llm4epR2CG_d_-N">https://example.com/payload.dmg#/ABCDFGJTUEJ/files/download/payload.jpg</a><br>2. it appears to be download the file &quot;payload.jpg&quot;<br>3.
