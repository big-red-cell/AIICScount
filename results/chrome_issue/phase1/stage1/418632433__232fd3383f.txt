<p><strong>Vulnerability type:</strong> Information Leak</p>
<h3>Details</h3>
<p>A private EC key (unittest_key_EC.pem) was accidentally committed and exposed in the public Chromium / AOSP repository under:
chromium/aosp/platform/system/update_engine/1cbbbb0772a666f60427dbbd122ff5189db424f8/.unittest_key_EC.pem
This private key is in PEM format and can be used to sign or authenticate update packages or other sensitive operations related to the update_engine component.
Because the key is publicly accessible, it poses a critical security risk:
Attackers could use the key to create forged update payloads.
Unauthorized code could be signed and delivered via the update system.
It undermines the integrity and trust of the update mechanism.
Impact:
Complete compromise of the update process for affected builds using this key.
Potential to distribute malicious updates to devices.</p>
<h3>Attack scenario</h3>
<p>Impact Analysis
Who can exploit:
Any attacker with access to the public repository or the exposed private key.
What they gain:
Ability to forge update payloads signed with the leaked key.
Capability to deliver malicious or unauthorized updates to devices relying on this key for verification.
Complete compromise of the update integrity and device security, potentially leading to remote code execution or persistent malware installation.
This vulnerability threatens the security and trust of the entire update process for affected devices.</p>
