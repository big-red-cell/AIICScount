<h3>The problem</h3>
<h4>Please describe the technical details of the vulnerability</h4>
<p>Vulnerability Overview:<br>
This vulnerability allows an attacker to spoof the Chrome browser&#39;s address bar by using fullscreen mode and a carefully crafted overlay. The attacker creates a fake Google login page that covers the entire browser window, hiding the real address bar and browser UI elements.</p>
<p>Technical Details:
The attack leverages the <code>fullscreen</code> API (<code>F11</code> or <code>Element.requestFullscreen()</code>) to hide browser UI including the address bar.<br>
A fake login page is displayed that visually mimics the legitimate Google login screen with realistic design elements.<br>
Since the address bar is hidden, users cannot verify the URL or domain, making it easy to trick them into entering their credentials.<br>
No special privileges or complex steps are required; the victim simply needs to visit a malicious link and switch to fullscreen or the page can request fullscreen automatically.<br>
This can be weaponized through phishing campaigns or social engineering.</p>
<p>Impact:<br>
Attackers can harvest sensitive user credentials by fooling users into believing they are logging into the real Google service, leading to potential account takeover and data compromise.</p>
<p>Reproduction Steps:</p>
<ol>
<li>Host the fake login page on a server (e.g., <code>http://localhost:8080</code>).</li>
<li>Open the page in Chrome browser.</li>
<li>Switch the browser to fullscreen mode (F11).</li>
<li>The fake login UI covers the entire screen, hiding the address bar.</li>
<li>Victim enters credentials unaware that the page is malicious.</li>
</ol>
<p>This vulnerability demonstrates a UI misrepresentation/spoofing flaw in Chrome&#39;s fullscreen implementation.</p>
<h4>Impact analysis – Please briefly explain who can exploit the vulnerability, and what they gain when doing so</h4>
<p>Who can exploit:<br>
Any attacker who can trick a victim into visiting a malicious link or page and persuading them to enter fullscreen mode can exploit this vulnerability. No special privileges or prior access is required.</p>
<p>What they gain:
The attacker can harvest the victim’s Google credentials by displaying a convincing fake login page without the real address bar or browser UI visible. This can lead to account takeover, unauthorized access to sensitive data, and further malicious activities on the victim’s Google account and associated services.</p>
