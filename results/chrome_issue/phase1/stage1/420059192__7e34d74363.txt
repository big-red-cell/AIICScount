# Problem Description
User flow during a visual spoofing scenario:
https://oval-profit-090.notion.site/Chrome-Visual-Spoofing-via-Userinfo-Same-script-Homoglyph-and-Subdomain-Tricks-1fe8238bd6a280828969c16470e3b23a?pvs=74

-------------------------
**Intro:
Certain URL structures — while fully valid and not inherently problematic — can still mislead users through realistic-looking patterns:
* Legitimate-looking links use `user@host` to hide the real destination.
* Long subdomains or homoglyphs push the actual domain to the right.
Notably, the spoofed example uses a homoglyph character ⁄ (U+2044, FRACTION SLASH) in place of the standard /. On Chrome with Google Sans and Pixel defaults, this renders nearly identically, making it difficult for users to detect the substitution at a glance.

-------------------------
**Example:
https://documents.google.com⁄document⁄d⁄1Hl_LY9shx$nUgZU&MZiJ49BfTBMswn7KrtHcgIKQ&@documents.google.com.document.d.1HlLY9shxnUWQZZUMZiQznJ49BfTBMswn7KrtHcgIKJ49B.mockWebsite.co/1Hl_LY9shx$nUgZU&MZiJ49BfTBMswn7KrtHcgIKQ/edit?pli=1&tab=t.0#heading=h.aagfqUm9.zw

**Will go to and view at URL area as:
https://documents.google.com.document.d.1HlLY9shxnUWQZZUMZiQznJ49BfTBMswn7KrtHcgIKJ49B.mockWebsite.co/1Hl_LY9shx$nUgZU&MZiJ49BfTBMswn7KrtHcgIKQ/edit?pli=1&tab=t.0#heading=h.aagfqUm9.zw

Even though the final domain is technically visible, users who already verified the beginning (https://documents.google.com/document⁄d⁄) — without expecting @ tricks — are likely to skip rechecking the full structure. The front portion looks identical during preview and post-redirect, which increases the chance of ignoring the critical difference.

-------------------------

**Impact:
Any long URL can easily be crafted to visually resemble a trusted domain

**Suggested Mitigations:
 1. Lightweight heuristics:
      In the address bar preview (or autocomplete/dropdown), if a URL includes @ and total length exceeds 30–50 characters (where users cannot immediately see the end of the domain), extract and display only the last 2–3 domain segments (e.g.,  (...).mockWebsite.co) in red or warning color — to encourage users to check more carefully, without disrupting normal UX.
 2. Advanced way:
      When a URL includes an `@` symbol, trigger a warning dialog clearly stating the actual destination domain, derived from the last 2 labels (e.g., `mockWebsite.co`).
      Offer options:
       • Always allow this domain
       • Allow this site only
       • Allow just this time
