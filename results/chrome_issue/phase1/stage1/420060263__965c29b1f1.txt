<h3>The problem</h3>
<h4>Please describe the technical details of the vulnerability</h4>
<p>Summary: A critical and highly impactful vulnerability has been identified within the <strong>Chromium core codebase</strong>, exploitable via a malicious Chrome extension. This flaw allows the extension to <strong>remotely and silently force-close the entire browser</strong> (Google Chrome, Microsoft Edge, Brave, Comodo Dragon, Avast Browser) and <strong>force-close all active tabs</strong> (Vivaldi Browser, Opera Browser), completely disrupting the user&#39;s Browse session without any warning, prompt, or consent.</p>
<p>Crucially, prior to entire browser / tab termination, this exploit initiates a <strong>complete and permanent wipeout of the user&#39;s entire Browse profile data</strong>. This includes:</p>
<ul>
<li>Browse History</li>
<li>Download History</li>
<li>Cookies and other site data (leading to complete logout from all sites)</li>
<li>Cached images and files</li>
<li>Passwords and other sign-in data (highly sensitive credentials)</li>
<li>Autofill form data (potentially containing sensitive personal information like addresses, payment details)</li>
</ul>
<p>This vulnerability has been confirmed across <strong>multiple major Chromium-based browsers</strong> (Google Chrome, Microsoft Edge, Brave, Comodo Dragon, Avast, Vivaldi, Opera), highlighting its widespread and devastating impact on billions of users.</p>
<p>A key aspect of this exploit is its <strong>universal and persistent nature</strong>. Once the malicious extension is installed, it operates silently and can be <strong>remotely triggered on ANY website or even upon typing keywords in the address bar</strong> (due to the <code>domains: [&quot;.&quot;]</code> configuration in the remote JSON). The attacker can control this behavior, including the activation of the full data wipeout, by simply modifying a remote JSON file – <strong>no extension update or user interaction is required post-installation.</strong></p>
<p>The combination of silent browser disruption, catastrophic and irreversible data loss (including credentials), universal remote control, persistence, and the ability for an attacker to cover their tracks makes this a severe privacy, security, and integrity issue. It offers a powerful mechanism for attackers to destroy digital evidence after potentially performing other malicious activities (e.g., data exfiltration).</p>

<p><strong>Expected Results:</strong>  The Chrome (and other Chromium-based) browser should <strong>never</strong> silently close or close all tabs without explicit user consent or a critical system error. User profile data (Browse history, download history, cookies, cached files, passwords, autofill data) should <strong>never</strong> be deleted by an extension or any other process without a clear, prominent, and undeniable user prompt/confirmation. Extensions should operate strictly within their defined permissions, and remote control mechanisms should not allow for the activation of highly destructive functionalities (like full data wipeout or browser termination) that bypass extension update review processes and direct user consent.</p>
<p><strong>Actual Results:</strong> As demonstrated, the malicious extension, through a Chromium core vulnerability, causes a silent browser/all-tabs closure and a complete, permanent wipeout of the user&#39;s entire profile data (history, passwords, cookies, cache, autofill) across multiple Chromium-based browsers, without any user warning or interaction. This behavior persists, can be remotely controlled and universally triggered on any website, and does not require any subsequent updates to the extension post-installation.</p>
<h4>Impact analysis – Please briefly explain who can exploit the vulnerability, and what they gain when doing so</h4>
<p>This vulnerability can be exploited by any malicious actor who successfully convinces a user to install this type of Chromium extension. This can be achieved through various vectors, including but not limited to, <strong>deceptive installations from the Chrome Web Store</strong> (by disguising the malicious extension as a legitimate or desirable tool), phishing campaigns, or deceptive advertising that tricks users into side-loading the extension.</p>
<p>Upon exploitation, the attacker gains the ability to:</p>
<ul>
<li><strong>Silently and remotely terminate the user&#39;s browser</strong> (google chrome browser, edge browser, brave browser, Comodo Dragon &amp; avast browser) or <strong>all active tabs</strong> (vivaldi browser &amp; opera browser), causing immediate disruption and preventing further Browse.</li>
<li><strong>Completely and permanently wipe out all user profile data</strong>, including highly sensitive information such as <strong>saved passwords, autofill data, Browse history, and cookies</strong>. This leads to irreversible data loss and destroys all digital evidence of attacker activity.</li>
<li><strong>Control the attack remotely and universally</strong>, as the exploit can be triggered on any website or search query without requiring any extension updates post-installation. This control is achieved by simply modifying a remote JSON configuration file.</li>
</ul>
<p>The primary gain for an attacker is <strong>catastrophic and irreversible data destruction</strong>, combined with the ability to perform a <strong>widespread denial of service</strong> across major Chromium-based browsers. Crucially, this vulnerability allows the attacker to <strong>cover their tracks</strong> after potentially exfiltrating sensitive information, by destroying all digital evidence on the affected system. The potential for distribution via official extension stores significantly amplifies the risk.</p>
