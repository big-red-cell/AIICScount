<h3>The problem</h3>
<h4>Please describe the technical details of the vulnerability</h4>
<p>The vulnerability arises from how Google Chrome handles local user profiles after a user signs out of their Google account.</p>
<p>When a user signs into Chrome and enables sync, Chrome downloads synced user data—including passwords, bookmarks, autofill information, and browsing history—and stores it in the local user profile directory (typically found under:
C:\Users&lt;username&gt;\AppData\Local\Google\Chrome\User Data\Profile <span>&lt;X&gt;</span> on Windows).</p>
<p>After signing out of the Google account via chrome://settings, the browser disconnects from the sync service, but it does not delete or encrypt the locally stored data. The Chrome profile remains listed on the profile selection screen and is still fully accessible.</p>
<p>If another person opens the browser using that profile, they can navigate to:</p>
<p>chrome://settings/passwords</p>
<p>chrome://history/</p>
<p>chrome://bookmarks/</p>
<p>…and access all previously synced and stored data without any authentication, even though the original Google account has been signed out.</p>
<p>The vulnerability lies in the lack of access control or encryption tied to the user&#39;s authentication status post-sign-out. Chrome does not require a password or 2FA to view stored credentials once downloaded via sync, leaving sensitive data exposed.</p>
<h4>Impact analysis – Please briefly explain who can exploit the vulnerability, and what they gain when doing so</h4>
<p>This vulnerability can be exploited by anyone with physical or remote access to the device where multiple Chrome user profiles exist. In shared environments such as schools, libraries, workplaces, or public computers, an unauthorized user can select a previously signed-out Chrome profile and gain full access to all locally stored synced data.</p>
<p>By exploiting this issue, an attacker can:</p>
<p>View and export saved passwords</p>
<p>Access browsing history, bookmarks, and autofill data</p>
<p>Potentially use saved credentials to compromise user accounts on other services</p>
<p>This leads to severe privacy violations and credential theft, allowing attackers to impersonate victims, access sensitive accounts, and cause financial or reputational damage.</p>
<p>Because Chrome does not require re-authentication after account sign-out for local profile access, this vulnerability exposes users’ sensitive information whenever profiles are left undeleted, even without access to the Google account itself.</p>
