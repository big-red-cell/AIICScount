<h1>Problem Description</h1>
<p>ulnerability Description
Two vulnerabilities were discovered in Google Chrome version 136.0.7103.125 (Official Build) (64-bit) that allow bypassing download permissions and notifications:</p>
<ul>
<li>Test 1: Files are downloaded without user consent, though the &quot;download complete&quot; notification appears afterward.</li>
<li>Test 2: Files are downloaded without user consent and without the &quot;download complete&quot; notification appearing in Chrome, leaving users unaware of the download.</li>
</ul>
<p>Impact
These vulnerabilities allow files to be downloaded without user consent in both tests.</p>
<ul>
<li>Test 1: Although the &quot;download complete&quot; notification appears after the file is downloaded, the download still happens without explicit user consent.</li>
<li>Test 2: The file is downloaded without any user consent, and no notification appears, leaving the user unaware of the download.</li>
</ul>
<p>These vulnerabilities can be exploited to distribute unwanted or potentially harmful files, jeopardizing the security of the user&#39;s device and compromising the user experience. The lack of transparency and control over the download process increases the risk to the user.</p>
<p>Severity: High
This vulnerability is classified as High Severity for the following reasons:</p>
<ul>
<li>Unauthorized downloads: Users do not have control over the downloading of files, which directly increases the risk to their devices and data. This vulnerability enables files to be downloaded automatically without the user&#39;s knowledge, which may contain harmful or unwanted content.</li>
<li>Loss of transparency: In Test 2, the file is downloaded without the user&#39;s knowledge, and no notification is shown, making the user unaware of the download. This reduces transparency and control over browser activities, potentially leading to a degraded user experience and security risks.</li>
<li>Potential for misuse: This vulnerability allows an attacker to automatically download files without user consent, which could be exploited to distribute unwanted files or malicious content.</li>
</ul>
<p>Overall, the vulnerabilities expose users to greater risks related to the security of their devices and data integrity. As a result, the severity of this issue is classified as High, and it requires immediate attention for mitigation.</p>
