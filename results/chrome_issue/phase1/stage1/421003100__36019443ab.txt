<h3>The problem</h3>
<h4>Please describe the technical details of the vulnerability</h4>
<h2>Description</h2>
<p>When opening a very large GIF file in the Response tab of the Chromium DevTools Network panel, a memory failure occurs in the V8 JavaScript engine with an &quot;invalid array length&quot; error message. This causes the Network tab to become unresponsive (hang) or crash, even though the main browser process continues to run.</p>
<p>The issue occurs when DevTools attempts to parse and render the full GIF response content in text or preview form, which results in an invalid array allocation and out-of-memory (OOM) in V8.</p>
