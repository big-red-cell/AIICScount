<hr>
<h3>The problem</h3>
<h4>Please describe the technical details of the vulnerability</h4>
<p>Please let me outline:</p>
<ol>
<li>GOOGLE Chrome Android has a feature for downloading a shown website as an archive file to the disc.</li>
<li>GOOGLE Mail has a feature for sending mails as confidential. A security measure of that feature would be that, e.g., neither downloading nor forwarding of that mail is allowed and possible.</li>
<li>Unfortunately, GOOGLE Chrome Android is not caring about that security measure.</li>
<li>Sent such a mail to somebody. Open the received link in GOOGLE Chrome Android and hit the &quot;Download&quot; button in the upper right corner behind the three-dot menu</li>
<li>Result: The actually not downloadable mail was downloaded. That downloaded file can be print and forwarded.</li>
<li>In a nutshell, the security features are not working in your browser.</li>
</ol>
<p>As you have seen I have highlighted the word GOOGLE. That means, both products are from the same company. The one department promises something, the other department is either not aware about that or ignoring these promises for whatever reason. :(</p>
<h4>Impact analysis – Please briefly explain who can exploit the vulnerability, and what they gain when doing so</h4>
<p>Receipients can download/share/print as confidential flagged mails in original quality.</p>
<p>That has to be stopped. The download feature has not be available when such a mail is shown in Chrome Android.</p>
<p>I have not tried if Chrome iOS/iPadOS and/or Windows and/or others are also ignoring these security settings.</p>
<p>Please mind: Yes, taking a camera would also be possible, but that is irrelevant in this case here.</p>

<h4>What version of Chrome have you found the security issue in?</h4>
<p>Chrome Android v136.0.7103.125</p>

<p>No, it is not related to a crash.</p>
