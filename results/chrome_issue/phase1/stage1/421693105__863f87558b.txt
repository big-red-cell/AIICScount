<h3>The problem</h3>
<h4>Please describe the technical details of the vulnerability</h4>
<p>Summary:</p>
<p>The GitHub repository GoogleChrome/chromium-dashboard publicly exposes a client_secrets.json file that contains a valid Google OAuth 2.0 client_id and client_secret.</p>
<p>These credentials are intended for use in installed applications but should still be treated as sensitive. An attacker could potentially abuse the secret in conjunction with phishing or OAuth flow manipulation to impersonate the application or access protected APIs.</p>
<p>Steps 2 Reproduce :</p>
<p>Follow the url :</p>

<h4>Impact analysis – Please briefly explain who can exploit the vulnerability, and what they gain when doing so</h4>
<p>The leaked client_secret can be used to:</p>
<pre><code>Facilitate unauthorized access to OAuth-protected resources (if scopes are sensitive).

Impersonate the application to end users in phishing or token abuse scenarios.

Register malicious OAuth apps masquerading as the official one.
</code></pre>
<p>If the associated redirect URIs are vulnerable or misconfigured, the issue may lead to token leakage or account takeover.</p>
