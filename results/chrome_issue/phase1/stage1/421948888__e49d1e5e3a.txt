<h1>Problem Description</h1>
<h3><strong>Affected Chrome Version:</strong></h3>
<p>136.0.7103.125 (Android 14 – CPH2363)</p>
<h3><strong>Description:</strong></h3>
<p>On Chrome for Android, when a download link is clicked from an app running in a floating window (overlay mode), the file is downloaded automatically without a visible download notification. This could enable <strong>spoofing</strong> scenarios and pose security risks.</p>
<hr>
<h3><strong>Potential Impact:</strong></h3>
<ul>
<li>File downloaded without visual indication.</li>
<li><strong>Spoofing</strong> of download notifications.</li>
<li>User unaware of the automatic download occurring in the background.</li>
</ul>
<hr>
<h3><strong>Suggested Mitigations:</strong></h3>
<ul>
<li>Ensure download notifications are always displayed <strong>on top of all windows</strong>, including overlays.</li>
<li>Delay or block automatic downloads triggered by third-party apps without explicit user interaction.</li>
</ul>
<hr>
<h1>Summary</h1>
<p>Download Spoofing in Chrome for Android via Floating Window Overlay</p>
