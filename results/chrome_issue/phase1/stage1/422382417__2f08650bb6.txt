right click on read instruction then choose &quot;open link in new window/incognito&quot;

<h1>Problem Description</h1>
<p>when window.open() alongside a data: URI window containing keyboard instructions like &quot;press tab tab enter&quot;. When launched simultaneously, the data: URI window becomes visible to the user, but focus is stolen by the programmatically opened window. If the user unknowingly follows the instructions (e.g., Tab, Tab, Enter), it could grant permissions (e.g., camera/microphone, notifications) without clear user intent.</p>
<h1>Summary</h1>
<p>Spoof to allow permission</p>
