<h3>The problem</h3>
<h4>Please describe the technical details of the vulnerability</h4>
<p>Description: 
When an attacker shares a download URL for a malicious file, they rename the file using a long string of empty spaces to obscure its actual name. As a result, when the victim clicks the link, the browser download prompt not display the correct file name, extension. This can trick the user into downloading the malicious file, as the browser fails to properly identify or warn about the file.</p>
<p>Steps-To-Reproduce:</p>
<ol>
<li>Open the URL in the Chrome browser - <a href="https://drive.google.com/file/d/1pq5eAhJ-mq8kb_-kv5cHiapHFBKyEyCG/view" data-b-widget="url" data-b-original-href="https://drive.google.com/file/d/1pq5eAhJ-mq8kb_-kv5cHiapHFBKyEyCG/view" data-b-redirected-href="https://www.google.com/url?q=https://drive.google.com/file/d/1pq5eAhJ-mq8kb_-kv5cHiapHFBKyEyCG/view&amp;sa=D&amp;source=buganizer&amp;usg=AOvVaw3bgbjemdWRUyWfNMqBMTkR">https://drive.google.com/file/d/1pq5eAhJ-mq8kb_-kv5cHiapHFBKyEyCG/view</a></li>
<li>Click Download -&gt; check the browser&#39;s download prompt</li>
<li>There is incorrect filename and extension</li>
</ol>
<p>Actual Behavior: 
Browser allow files with excessive whitespace in their names to be downloaded without showing the full filename, extension, or source domain in the download prompt.</p>
<p>Expected Behavior: 
Browser should display the full filename, including its extension and source domain, regardless of any whitespace or special characters used in the name.</p>
<h4>Impact analysis – Please briefly explain who can exploit the vulnerability, and what they gain when doing so</h4>
<p>Impact: This can lead users to unknowingly download and execute malicious files, bypassing basic user awareness and browser-level safety cues, increasing the risk of malware infection.</p>
