<h3>The problem</h3>
<h4>Please describe the technical details of the vulnerability</h4>
<p>Subject: Arbitrary Code Execution via Google Updater Service (Signature Validation Bypass)</p>
<ol>
<li><strong>Vulnerability Summary</strong>:
-Title: Unsigned Code Execution via updater.exe Replacement in Google Update
-Risk: Critical (Presistance Backdoor + Arbitrary Code Execution + Privilege Escalation to SYSTEM)
-Affected Product: Google Update Service (GoogleUpdate.exe)
-Affected Versions: Tested on version 137.0.7151.57 (Official Build) (64-bit)
-Attack Vector: Local (requires admin/privileged access initially)
==================================================</li>
<li><strong>Vulnerability Details</strong>
(Root Cause):
The Google Update Service (GoogleUpdate.exe) executes the binary updater.exe from C:\Program Files (x86)\Google\GoogleUpdater\138.0.7194.0\ without validating its digital signature or cryptographic hash. This allows an attacker with administrative privileges to replace updater.exe with a malicious executable, which will then be executed malicious code And Too with SYSTEM privileges when:
-A user checks for updates (e.g., via Chrome’s &quot;About&quot; page).
-Scheduled update tasks run.</li>
</ol>
<h1><strong>Proof of Concept (PoC)</strong>:
-Replace updater.exe with a custom binary:
<code>rename &quot;C:\Program Files (x86)\Google\GoogleUpdater\138.0.7194.0\updater.exe&quot; updater2.exe move updater.exe &quot;C:\Program Files (x86)\Google\GoogleUpdater\138.0.7194.0&quot;</code>
2.Execute It (2 Diffrent Ways):
-Open Settings - About Chrome And It Will Execute Automatic (Easy Way)
-Excute It With Cmd (net start) Command</h1>
<h1>3.Result:
-the malicious code will execute and with system privilges (Code Execution + Privilege Escalation):
-Creating Files priv.txt - user.txt - allpriv.txt</h1>
<ol start="4">
<li>Steps to Reproduce
-Replace updater.exe as described above.
-Trigger the updater (via service restart or Chrome’s &quot;About&quot; page).-
-Observe payload execution at SYSTEM level.</li>
<li>Mitigation Recommendations
-Enforce signature validation: Ensure updater.exe is signed by Google and verify its Authenticode signature before execution.
-Implement hash checking: Compare the binary against a whitelisted SHA-256 hash.
-Sandbox the updater: Run GoogleUpdateService with reduced privileges (e.g., as LOCAL SERVICE).
-Monitor file integrity: Alert on modifications to updater.exe (e.g., via Sysmon).</li>
</ol>
<h4>Impact analysis – Please briefly explain who can exploit the vulnerability, and what they gain when doing so</h4>
<p><strong>Imapct</strong>:
-Attacker Execute Malicious Codes On System
-Attcker will Gain Full Access On System By (SYSTEM Privileges)
-Attacker will Gain Presistance Because re-executes on every update check.
-Causing Data Theft (Lsass Dumping, Presistance, Steal Using Create Sessions)</p>
