<h1>Steps to reproduce the problem</h1>
<ol>
<li>Open <code>https://umar1105.github.io/inpoc</code> in <strong>Google Chrome (Android Pixel 5)</strong> using <strong>Incognito mode</strong>.</li>
<li>Tap anywhere on the page or tap the &quot;New Tab&quot; icon.</li>
<li>Observe: The browser automatically triggers a redirect to <code>evil.com</code> in another browser or external app.</li>
</ol>
<h1>Problem Description</h1>
<p><strong>Summary:</strong></p>
<p>A security flaw in <strong>Google Chrome for Android&#39;s Incognito Mode</strong> allows a malicious webpage (e.g., <code>umar1105.github.io/inpoc2</code>) to force an automatic redirect to a harmful external site (e.g., <code>evil.com</code>) in another browser or app with minimal user interaction, such as tapping anywhere or clicking the &quot;New Tab&quot; icon</p>
<p><strong>Expected Behavior:</strong></p>
<ul>
<li>The webpage should display benign content only.</li>
<li>Any tap or UI interaction should <strong>not</strong> trigger redirects, especially those that leave Chrome or Incognito mode.</li>
</ul>
<p><strong>Actual Behavior:</strong></p>
<ul>
<li>After a tap or UI interaction, the page triggers an <strong>intent-based redirect</strong>, causing Chrome to open an external browser or app (e.g., system browser).</li>
<li>The user is silently moved out of Incognito context, violating expected privacy behavior.</li>
</ul>
<p><strong>Impact:</strong></p>
<ul>
<li><strong>Security boundary bypass</strong>: Content from an Incognito session escapes the sandboxed environment.</li>
<li><strong>User tracking or phishing risk</strong>: Redirected to a malicious site in another browser with full cookie/context exposure.</li>
<li><strong>Privacy violation</strong>: The redirect may be logged or tracked by the new browser, defeating Incognito protections.</li>
<li><strong>Abuse potential</strong>: Can be exploited for deceptive ads, malware delivery, or persistent tracking.</li>
</ul>
<p><strong>Supporting References:</strong></p>
<ul>
<li>Chromium Issue (similar root cause): <a href="https://issues.chromium.org/issues/352516283" data-b-widget="issue-reference" data-b-issue-id="352516283">https://issues.chromium.org/issues/352516283</a></li>
</ul>
<p><strong>Suggested Mitigation:</strong></p>
<ul>
<li>Block automatic external redirects triggered by minimal gestures (tap, new tab) in Incognito Mode.</li>
<li>Require <strong>explicit user confirmation</strong> before launching external apps or browsers.</li>
<li>Harden Incognito mode to prevent <strong>context-leaking via implicit intent redirects</strong>.</li>
</ul>
