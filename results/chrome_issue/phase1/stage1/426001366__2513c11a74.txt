<h3>The problem</h3>
<h4>Please describe the technical details of the vulnerability</h4>
<h1>Overview</h1>
<p>Chrome has a password manager feature, users can sign into a Gmail account and have their credentials saved into the Google password manager.</p>
<p>On Windows accessing this password manager requires Windows user account password but recently Google has introduce a new feature called &quot;Select password&quot; where you can right click on a form field and load passwords from password manager without entering Windows user account password.</p>
<h2>Reproduce</h2>
<p>Make sure you are logged into Chrome with sync enabled and have saved passwords in Chrome’s built-in password manager.</p>
<p>To reproduce this issue, open Google password manager:
chrome://password-manager/passwords</p>
<p>Ensure you have at least one password saved for a website. Click on the website and you will be prompted to enter Windows user account password or PIN.</p>
<p>Now, to access this password, just open any website with form fields, for example, W3Schools form:
<a href="https://www.w3schools.com/html/html_forms.asp" data-b-widget="url" data-b-original-href="https://www.w3schools.com/html/html_forms.asp" data-b-redirected-href="https://www.google.com/url?q=https://www.w3schools.com/html/html_forms.asp&amp;sa=D&amp;source=buganizer&amp;usg=AOvVaw3BAb8gGpnEnkVRYqhvfduN">https://www.w3schools.com/html/html_forms.asp</a></p>
<ol>
<li>Right click on a form field.</li>
<li>Select &quot;Select password&quot;</li>
<li>Click an account &amp; then a new dropdown opens up, click &quot;Fill password&quot;</li>
<li>Finally click &quot;Use password&quot;</li>
</ol>
<p>This will allow you to load the password without auth.</p>
<h4>Impact analysis – Please briefly explain who can exploit the vulnerability, and what they gain when doing so</h4>
<h1>Impact</h1>
<p>The &quot;Select password&quot; feature in Chrome allows saved credentials to be autofilled into web forms without requiring OS-level authentication, bypassing the protections enforced by the main password manager interface (chrome://password-manager/passwords), which does require Windows reauthentication (e.g., via PIN or Hello).</p>
<p>This creates an inconsistency in Chrome’s security model where access to the same sensitive data such as user credentials is gated in one context but not another.</p>
<p>This is easily exploitable with hidden VNC malware, traditionally, it would require user account password to access passwords saved to Google password manager but now, we can exfiltrate passwords just by browsing a website with forms and using the new &quot;Select password&quot; feature.</p>
