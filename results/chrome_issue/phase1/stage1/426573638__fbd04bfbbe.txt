<h1>Problem Description</h1>
<p>This report demonstrates a UI deception vulnerability in Chromium-based browsers, where the Notification.requestPermission() API is used not to gain permission, but to intentionally suppress the native autofill UI. This allows a malicious webpage to render a spoofed autofill dropdown, tricking the user into believing it originates from the browser, and then silently exfiltrating their email address to an attacker-controlled server.</p>
<p>The problem is not with Notification itself, but with how its prompt takes visual focus and delays or suppresses native UI events — particularly autofill suggestions. When timed precisely, this can be abused to intercept the autofill moment and replace it with a visually identical, but malicious, dropdown.</p>

<p>Autofill Spoof via Prompt Suppression Enables Silent Email Exfiltration</p>
