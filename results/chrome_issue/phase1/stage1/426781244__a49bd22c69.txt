<p><strong>IMPACT</strong></p>
<p>Email addresses and identity-related fields can be harvested in a zero-click or low-click manner.</p>
<h1>Problem Description</h1>
<p>A login input field can be exploited to silently exfiltrate user-typed data — such as an email address — using a combination of localStorage and the blur event. This allows an attacker to capture sensitive user input without the need for any explicit interaction, such as clicking a submit button or confirming a browser prompt.</p>
