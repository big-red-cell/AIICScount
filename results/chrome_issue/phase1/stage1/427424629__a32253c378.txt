<h1>Problem Description</h1>
<p>In this Vulnerability Attacker can be able to execute external protocol if user tap on anywhere on Address Bar, Home Icon, Back button, Tab Menu
which leads to execution of malicious intent links using window.onblur function</p>
<p>The core issue is that user interaction with standard, seemingly safe browser UI elements (Address Bar, Home Icon, Back button, Tab Menu) can be leveraged to trigger the execution of external protocols</p>
<p>The vulnerability exploits actions that users perform routinely and without suspicion, making it highly effective for tricking victims. A tap on the address bar to edit a URL or a tap on the back button to navigate can inadvertently launch a malicious link.</p>
<p>Since the interaction appears benign (tapping a browser UI element), users are unlikely to suspect a malicious action is taking place, making the attack highly stealthy and effective.</p>

<p>Execute external Protocol &amp; Intent if user tap on Address bar, Home, tab menu, back button Android</p>
