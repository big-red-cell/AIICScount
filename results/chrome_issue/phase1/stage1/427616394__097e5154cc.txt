<p><strong>Vulnerability type:</strong> Security UI Spoofing</p>
<h3>Details</h3>
<p>Description:
A bug in Google Chrome allows a text caret (blinking typing cursor) to appear anywhere on the screen when clicking, even in non-editable areas of a webpage or browser UI. This behavior mimics the behavior of a selectable/focusable field but occurs in unintended regions, such as outside input fields, in plain page text, or UI elements like settings, bookmarks bar, etc.</p>
<p>This may:</p>
<p>Confuse users into thinking a field is editable.</p>
<p>Cause UI inconsistency or overlay glitches.</p>
<p>Potentially be abused in phishing/redressing attacks (if focus behavior is spoofed).</p>
<p>Steps to Reproduce:
Open Chrome and navigate to any standard webpage (e.g., <a href="https://www.google.com" data-b-widget="url" data-b-original-href="https://www.google.com" data-b-redirected-href="https://www.google.com/url?q=https://www.google.com&amp;sa=D&amp;source=buganizer&amp;usg=AOvVaw0xHc4PnJ-5PnGXiIvS00h7">https://www.google.com</a>).</p>
<p>Click anywhere in the body of the page, outside of any input field.</p>
<p>Observe a blinking text cursor (caret) appearing where you clicked, even though there is no input box or editable element.</p>
<h3>Attack scenario</h3>
<p>UI spoofing: Attackers could mimic an input field or trick users into believing they can type somewhere when they can’t.</p>
<p>Accessibility issues: Screen readers may respond inappropriately to unintended caret focus.</p>
<p>Potential use in clickjacking or redressing if combined with other UI manipulation techniques.</p>
