<h1>Problem Description</h1>
<p>chrome Browser allows calling navigator.share() from within an iframe, and pops up the native share prompt without stating the origin of the calling frame. This causes UI origin confusion, where the user thinks the prompt is coming from the main (trusted) page, when it is coming from an attacker-controlled iframe.</p>
<h1>Expected results</h1>
<p>navigator.share() should only be callable from window.top, not from sandboxed/nested iframes.
Can only be triggered from a top-level browsing context with a gesture in that context</p>
<h1>Actual results</h1>
<p>Gesture from parent is used by iframe, Safari considers gesture still valid after reload
Can be triggered from a sandboxed iframe, after reloading - even if there is no gesture in the iframe</p>
<h1>Summary</h1>
<p>navigator.share() Prompt Misattribution from Iframe Context</p>
