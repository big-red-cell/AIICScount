<h1>Problem Description</h1>
<p>The vulnerability stems from the recursive nature of XMLSerializer::serializeToString (which internally calls MarkupAccumulator::SerializeNodes and SerializeNodesWithNamespaces). When serializing a DOM tree with an exceptionally large number of nested child elements (e.g., a depth of 100,000 or more), each recursive function call consumes space on the program&#39;s call stack.
While modern browsers like Chromium employ multi-process architecture to isolate tabs and mitigate the impact of renderer crashes, and JavaScript engines have their own recursion limits, this specific scenario bypasses the JavaScript-level checks and directly triggers a native C++ stack exhaustion. The continuous allocation of stack frames for each recursive call eventually exceeds the operating system&#39;s allocated stack size for the renderer process.</p>
<h1>Summary</h1>
<p>XMLSerializer stack-overflow via deep DOM tree leads to renderer process crash.</p>
