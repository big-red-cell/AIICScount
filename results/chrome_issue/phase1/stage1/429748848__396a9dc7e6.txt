<h3>Report description</h3>
<p>When using Ctrl+click or Shift+click, the SameSite restrictions and iframe sandboxing can be bypassed.</p>

<h3>Bug location</h3>
<h4>Where do you want to report your vulnerability?</h4>
<p>Chrome VRP – Report security issues affecting the Chrome browser. <a href="https://bughunters.google.com/about/rules/5745167867576320/chrome-vulnerability-reward-program-rules" data-b-widget="url" data-b-original-href="https://bughunters.google.com/about/rules/5745167867576320/chrome-vulnerability-reward-program-rules" data-b-redirected-href="https://www.google.com/url?q=https://bughunters.google.com/about/rules/5745167867576320/chrome-vulnerability-reward-program-rules&amp;sa=D&amp;source=buganizer&amp;usg=AOvVaw31QXnMd5mgu42yXMeOAv3K">See program rules</a></p>
<hr>
<h3>The problem</h3>
<h4>Please describe the technical details of the vulnerability</h4>
<p>If a link inside an iframe is clicked using Ctrl+click or Shift+click, not only are SameSite=Strict cookies sent, but all sandbox attributes of the iframe are ignored. Furthermore, the newly opened window does not inherit any of the iframe&#39;s sandbox restrictions.</p>
<h4>Impact analysis – Please briefly explain who can exploit the vulnerability, and what they gain when doing so</h4>
<p>If a user mistakenly uses Ctrl or Shift while clicking, SameSite restrictions can be bypassed, making them vulnerable to CSRF attacks. Additionally, sandbox attributes can be bypassed, allowing malicious JavaScript code to execute.</p>
