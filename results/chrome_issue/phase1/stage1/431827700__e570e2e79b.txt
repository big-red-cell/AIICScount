<h3>The problem</h3>
<h4>Please describe the technical details of the vulnerability</h4>
<p>Hello,</p>
<p>I have opened a file named Login Data located in the following directory on my computer:</p>
<p>C:\Users[Username]\AppData\Local\Google\Chrome\User Data\Default
using an SQL viewer program. I noticed that the stored usernames inside the file can be easily read.</p>
<p>This raises serious concerns about how Google Chrome stores user data. Especially the fact that usernames are stored without encryption poses a risk to data privacy.</p>
<p>I would like to inquire about:</p>
<p>Why usernames are stored without encryption,</p>
<p>Any existing or planned security measures regarding this issue,</p>
<p>Official documentation and explanations related to this matter.</p>
<p>Please let me know if you require any additional information.</p>
<p>Thank you,</p>
<h4>Impact analysis – Please briefly explain who can exploit the vulnerability, and what they gain when doing so</h4>
<p>The security vulnerability can be exploited by malicious third parties, such as hackers or malware authors who seek unauthorized access to your computer or user data. By exploiting this vulnerability, they can obtain unencrypted information like usernames, which can then be used maliciously.</p>
<p>Such information may be used for identity theft, account takeover, social engineering attacks, or other fraudulent activities. As a result, users&#39; privacy is compromised, and security risks arise.</p>
