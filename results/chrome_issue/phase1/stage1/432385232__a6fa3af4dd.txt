<h1>Problem Description</h1>
<p>Chrome on Android allows a webpage to trigger a file download automatically during page load without requiring any user interaction (click, tap, or gesture). This bypasses the browser’s intended security model that mandates user gestures to initiate downloads, enabling potential drive-by downloads of arbitrary files such as APKs.</p>
