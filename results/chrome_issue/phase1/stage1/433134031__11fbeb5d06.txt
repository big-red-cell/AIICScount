Security Bug<br><br>-------------------------<br><br>VULNERABILITY DETAILS<br><br>I find that even if I enable &quot;Always use secure connections&quot; and choose &quot;Warns you for insecure public sites&quot;, Chrome doesn&#39;t warn me when I type a http URL in the address bar and press Enter. Chrome loads the site over plaintext http. See the screen recording attachment.<br><br>The impact is that man-in-the-middle attackers block outgoing connections to port 443. In this case, Chrome silently allows users to navigate to sites over http, and this can leak users&#39; browsing activities to MITM attackers and can make users more vulnerable to phishing by MITM.<br><br>For example, MITM can first block all port 443 requests.
