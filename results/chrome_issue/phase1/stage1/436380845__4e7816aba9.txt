<h3>The problem</h3>
<h4>Please describe the technical details of the vulnerability</h4>
<p><strong>JavaScript Execution in Chrome PDF Viewer Enables Credential Exfiltration via submitForm()</strong></p>
<hr>
<h3>Description :</h3>
<p>Chrome’s built-in PDF viewer executes embedded JavaScript in PDF files without proper restrictions or user consent. This allows an attacker to create a PDF file that collects sensitive data (e.g., email and password) through form fields and exfiltrates the data using <code>this.submitForm()</code> to an external server.</p>
<p>This behavior can be exploited for phishing attacks. Since the PDF is rendered within Chrome, users are more likely to trust it.</p>
<hr>

<ol>
<li>
<p>Open the attached PDF file (<code>phishing_form.pdf</code>) in Google Chrome (latest version tested: <strong>[Version 138.0.7204.184]</strong>)</p>
</li>
<li>
<p>Enter dummy email and password.</p>
</li>
<li>
<p>Click on the &quot;Submit&quot; button.</p>
</li>
<li>
<p>The script runs:</p>
<ul>
<li>Shows an alert with email/password.</li>
<li>Attempts to send the data to:
<code>https://webhook.site/8e9a444f-a8de-46de-a0cc-3eba6062ed28?...</code></li>
</ul>
</li>
</ol>
