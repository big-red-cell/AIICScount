Author: jd...@chromium.org
<p>Thanks for the report. The &quot;Always Use Secure Connections&quot; setting is specifically designed to mitigate the risks of insecure network protocols (e.g. HTTP) being used to load the main frame. It does not protect against HTTP present in iframes.</p>
<p>Typically, iframes loaded over HTTP are blocked when accessing a main frame over HTTPS (as a form of mixed content). However, these protections do not apply to locally-opened files so as to facilitate local site development.</p>
<p>That means that yes, &quot;Always Use Secure Connections&quot; does not fully prohibit Chrome from ever making an HTTP request. We may expand protections in the future to be stronger, but at this point this is working as expected.</p>
