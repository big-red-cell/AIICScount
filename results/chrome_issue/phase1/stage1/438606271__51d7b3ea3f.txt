<h1>Problem Description</h1>
<p>Actual Result
In Scenario B, the preview hides the true domain (xn--googl-fsa.com) and shows only the visually deceptive portion, enabling a homograph phishing scenario.</p>
<p>Expected Result
Regardless of gesture, the link preview should always ensure the registrable domain (<code>eTLD+1</code>) is visible in full, especially when IDN domains are used.</p>
<p>Impact / Security Concerns
This issue allows attackers to combine long subdomain/path truncation with IDN homograph attacks to trick users into believing they are visiting a trusted domain like google.com. The long-press+drag gesture bypasses the normal full-URL preview and makes the deception more effective. This is particularly risky on Chrome iOS because users may rely on preview for link safety checks before clicking.</p>
<h1>Summary</h1>
<p>[Chrome iOS] Link Preview Truncates Domain on Long-Press + Drag, Enabling IDN Homograph Phishing</p>
