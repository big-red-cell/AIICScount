This non-user-initiated default choice enables a complete circumvention of subsequent MFA validations for that device, persisting even after password changes.

This creates a state of session confusion, which an attacker can exploit.
 * Multi-Context Attack Vectors: This vulnerability is demonstrable across scenarios involving both:
   * Multiple devices and multiple user IDs.
   * A single device with multiple user IDs, eliminating the need for an attacker to compromise a separate physical device.
 * Malicious Recovery Email Injection: A particularly alarming finding is the potential for an attacker to inject an attacker-controlled email address (e.g., petrushka.googol@gmail.com) into the target's account recovery options. The observation of such an injected email appearing in subsequent login/recovery dropdowns, alongside the offer of a "stored password," serves as direct evidence of this severe compromise capability.

The concatenation of these identified vulnerabilities culminates in a CODE RED security assessment, signaling an immediate and profound threat:
