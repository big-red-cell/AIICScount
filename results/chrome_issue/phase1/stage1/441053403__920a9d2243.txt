<h3>The problem</h3>
<h4>Please describe the technical details of the vulnerability</h4>
<p>When multiple Chrome profiles are active, if a file download is initiated in Profile A and Chrome for that profile is closed mid-download, the download process continues under Profile B. This behavior contradicts the principle of strict profile isolation and indicates improper session separation.</p>
<h4>Impact analysis – Please briefly explain who can exploit the vulnerability, and what they gain when doing so</h4>
<p>This flaw allows unintended cross-profile persistence of downloads, which can mislead users about the state of their activities. It may expose sensitive download data in another profile, break expected privacy boundaries, and potentially enable security policy bypass in environments where profiles have different privileges.</p>
