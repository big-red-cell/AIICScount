<p>A new tab opens and <strong><code>alert(1)</code> executes</strong>, showing a <strong>sandbox escape</strong>.</p>
<h2>Recommendations:</h2>
<ul>
<li>Enforce strict sandbox policy compliance in all Chromium versions.</li>
<li>Ensure popups opened by sandboxed iframes inherit their sandbox unless <code>allow-popups-to-escape-sandbox</code> is set.</li>
<li>Prevent popups from bypassing global popup-block settings via programmatic iframe navigation.</li>
</ul>
<h1>Problem Description</h1>
<ul>
<li>
<p>Chrome incorrectly allows <strong>sandboxed iframes</strong> using the <code>sandbox</code> attribute (without <code>allow-popups-to-escape-sandbox</code>) to spawn <strong>unsandboxed popups</strong> that can execute <strong>arbitrary JavaScript</strong>, <strong>bypassing</strong> expected security restrictions and <strong>user settings</strong>.</p>
</li>
<li>
<p>This behavior violates the <a href="https://html.spec.whatwg.org/multipage/iframe-embed-object.html#attr-iframe-sandbox" data-b-widget="url" data-b-original-href="https://html.spec.whatwg.org/multipage/iframe-embed-object.html#attr-iframe-sandbox" data-b-redirected-href="https://www.google.com/url?q=https://html.spec.whatwg.org/multipage/iframe-embed-object.html%23attr-iframe-sandbox&amp;sa=D&amp;source=buganizer&amp;usg=AOvVaw2cW3BQuF8IybjtojhpdQaA">HTML specification for sandboxed iframes</a>, and undermines Chrome’s built-in protections related to iframe isolation, cross-origin restrictions, and popup control.</p>
</li>
</ul>
<h3>Affected Products:</h3>
<ul>
<li><strong>Google Chrome Stable</strong> – Version: <code>139.0.7258.139</code></li>
<li><strong>Google Chrome Canary</strong> – Version: <code>141.0.7375.3</code></li>
<li><strong>Platform</strong>: macOS Sequoia 15.6.1</li>
</ul>
<h2>Impact:</h2>
<p>An attacker can:</p>
<ul>
<li><strong>Escape iframe sandboxing</strong>.</li>
<li><strong>Execute arbitrary JavaScript in a new tab/window</strong>.</li>
<li><strong>Bypass popup blocking mechanisms</strong>.</li>
<li><strong>Launch phishing, clickjacking, or XSS attacks</strong>.</li>
<li>Exploit <strong>cross-origin sandboxed content</strong> to escalate privileges.</li>
</ul>
