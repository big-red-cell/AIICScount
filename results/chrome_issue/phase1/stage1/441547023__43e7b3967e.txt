Author: Thank you for reporting. As leimy@ explained, this should be working as intended. In the current implementation, prerendering doesn't care about cookie changes, and instead developers need to handle them (e.g., canceling prerendering on cookie changes, or not triggering prerendering for sensitive pages).

Regarding differences in Chrome versions (reproducible on M141 and M140 but not on M139), I suspect there is another issue here. Could you check if prerendering is properly triggered using DevTools? You can check status of prerendering on the "Speculative loads" pain in the "Application" tab. See https://developer.chrome.com/docs/devtools/application/debugging-speculation-rules#prerender for more details.

Anyway, I think the original issue is not a new regression in M141 and M140 (rather behavior on these versions is more correct), so we don't need to block launches.
