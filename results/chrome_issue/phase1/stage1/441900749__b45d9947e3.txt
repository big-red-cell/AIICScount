<h2>Recommendations:</h2>
<ul>
<li>Enforce <strong>strict sandbox policy compliance</strong> across all Chromium versions.</li>
<li>Ensure <strong>popups opened by sandboxed iframes</strong> inherit the sandbox <strong>unless</strong> <code>allow-popups-to-escape-sandbox</code> is explicitly set.</li>
<li>Prevent popups from <strong>bypassing global popup-block settings</strong> through programmatic iframe-based navigation.</li>
</ul>
<h1>Problem Description</h1>
<ul>
<li>A <strong>sandbox escape vulnerability</strong> exists in **Chrome Stable , Chrome  Canary, Chrome Beta for Android **, which allows JavaScript to execute <strong>outside</strong> the sandboxed iframe constraints <strong>without</strong> using <code>allow-popups-to-escape-sandbox</code> or <code>allow-modals</code>. This issue results in <strong>Universal Cross-Site Scripting (UXSS)</strong>.</li>
<li>The same payload <strong>fails</strong> in Chrome for <strong>macOS</strong>, confirming that the issue is <strong>Android-specific</strong> (iOS not verified).</li>
</ul>

<h2>Sandbox Escape Behavior – Chrome for Android vs Desktop</h2>
<ul>
<li>When you open <code>a.html</code>, it loads an <code>&lt;iframe&gt;</code> that contains <code>sandbox.html</code>. <code>sandbox.html</code> attempts to open <code>xss.php</code> in a <strong>named iframe</strong> and execute JavaScript (JS) from the URL.</li>
</ul>
<h2>Expected Behavior:</h2>
<ul>
<li>If the <strong>sandbox is functioning correctly</strong>, the JavaScript should <strong>not execute</strong> due to sandbox restrictions.</li>
</ul>
<h3>Observed Behavior on Chrome for Android:</h3>
<ul>
<li>
<p>On <strong>Chrome for Android</strong>, the sandbox restrictions are <strong>bypassed</strong>, allowing the JavaScript to <strong>successfully execute</strong>.</p>
</li>
<li>
<p>This occurs <strong>without</strong> the use of the following attributes:</p>
</li>
<li>
<p><code>allow-modals</code></p>
</li>
<li>
<p><code>allow-popups-to-escape-sandbox</code></p>
</li>
</ul>
<h2>Observed Behaviour on Chrome for macOS (Desktop):</h2>
<ul>
<li>
<p>On <strong>Chrome for macOS</strong>, the JavaScript <strong>does not execute</strong>, as the sandbox <strong>is not escaped</strong>.</p>
</li>
<li>
<p>The <strong>Developer Console</strong> logs the following messages:</p>
</li>
<li>
<p>&quot;An iframe which has both <code>allow-scripts</code> and <code>allow-same-origin</code> for its sandbox attribute can escape its sandboxing.&quot;_</p>
</li>
<li>
<p>&quot;xss.php?js=alert(1):5 Ignored call to &#39;alert()&#39;. The document is sandboxed, and the &#39;allow-modals&#39; keyword is not set.&quot;</p>
</li>
</ul>
<h2>Summary:</h2>
<ul>
<li><strong>Chrome Android</strong>: Sandbox escape <strong>successful</strong>, JS executes without required attributes.</li>
<li><strong>Chrome macOS</strong>: Sandbox <strong>enforced</strong>, JS blocked as expected.</li>
<li>I have uploaded the proof of concept image and video in this report for your review and reference.</li>
</ul>
