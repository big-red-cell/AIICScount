<h1>Steps to reproduce the problem</h1>
<ol>
<li>
<p>Open Chrome on Android (139.0.7258.158 or Beta 140.0.7339.47).</p>
</li>
<li>
<p>Visit:</p>
<pre><code>https://attacker.hackerbro.net/spooftest.html
</code></pre>
</li>
<li>
<p>The page opens <code>about:blank</code> with a &quot;security verification required&quot; message, then automatically redirects to:</p>
<pre><code>http://testsafebrowsing.appspot.com/apiv4/ANY_PLATFORM/MALWARE/URL/
</code></pre>
</li>
</ol>
<p><strong>Observed Behavior:</strong></p>
<ul>
<li>No Safe Browsing warning is displayed.</li>
<li>The page loads directly, despite being a known Safe Browsing malware test endpoint.</li>
</ul>
<p><strong>Expected Behaviour:</strong></p>
<ul>
<li>
<p>Chrome should show the &quot;Dangerous site&quot; red interstitial warning, as seen on Chrome Desktop:</p>
<blockquote>
<p><em>“Dangerous site: Attackers on the site that you tried visiting might install harmful software… Chrome strongly recommends going back to safety.”</em></p>
</blockquote>
</li>
</ul>
<h1>Problem Description</h1>
<ul>
<li>A Safe Browsing bypass exists in Chrome for Android where malicious URLs that normally trigger a &quot;Dangerous site&quot; interstitial instead load directly without warning.</li>
</ul>
<p><strong>Test Environment:</strong></p>
<ul>
<li>Google Chrome 139.0.7258.158 (Android)</li>
<li>Google Chrome Beta 140.0.7339.47 (Android)</li>
</ul>
<p><strong>Impact:</strong></p>
<ul>
<li>Malicious websites can bypass Safe Browsing interstitials on Chrome Android, exposing users to phishing or malware without user warnings.</li>
<li>Verified on both stable and beta builds.</li>
</ul>

<p>Safe Browsing Warning/Interstitial Bypass/Missing in Chrome Android</p>
