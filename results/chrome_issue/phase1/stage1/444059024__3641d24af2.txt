<h1>Steps to reproduce the problem</h1>
<p>1️⃣ Host the attached PoC file (download.html) on a server.</p>
<p>2️⃣ Open the PoC URL in Microsoft Edge for iOS.</p>
<p>3️⃣ Click the button on the page.</p>
<p>4️⃣ Microsoft Edge opens Google.com (or another trusted site) in a new tab.</p>
<p>5️⃣ Within 1 second, a file download prompt appears while Google.com is still displayed in the omnibox.</p>
<p>6️⃣ The user, trusting that the download is from Google.com, downloads the file.</p>
<h1>Problem Description</h1>
<p>A security vulnerability in Microsoft Edge for iOS allows an attacker to spoof the origin of a file download, tricking users into believing they are downloading a file from a trusted website (e.g., Google.com). This occurs when a background tab triggers a file download, while the omnibox (address bar) continues to display a different, legitimate site.</p>
<p>By exploiting this flaw, attackers can manipulate users into downloading malicious files, disguising them as legitimate downloads from trusted domains such as Google.com or Microsoft.com. This can lead to phishing attacks, malware distribution, and security bypasses.</p>
<p>A similar vulnerability was previously identified in Chrome (Chromium <a href="https://issues.chromium.org/issues/40061023" data-b-widget="issue-reference" data-b-issue-id="40061023">Bug 40061023</a>), where a background tab could initiate a download in another tab, misleading users about the true source of the file. Chrome has since patched this issue through this commit(<a href="https://chromium-review.googlesource.com/c/chromium/src/+/6062881" data-b-widget="url" data-b-original-href="https://chromium-review.googlesource.com/c/chromium/src/+/6062881" data-b-redirected-href="https://www.google.com/url?q=https://chromium-review.googlesource.com/c/chromium/src/%2B/6062881&amp;sa=D&amp;source=buganizer&amp;usg=AOvVaw31d505sGnyaR_cNO2b-Hw1">https://chromium-review.googlesource.com/c/chromium/src/+/6062881</a>), which introduces a new security measure to display the actual originating host of the download in the download bar when it differs from the website in the omnibox.</p>
