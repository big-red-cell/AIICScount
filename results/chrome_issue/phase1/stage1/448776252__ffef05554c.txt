# Problem Description
Summary:
While opening a crafted PDF file in Chrome (Version 140.0.7339.185 (Official Build) (64-bit)) on Windows 10, a JavaScript payload embedded in the PDF triggers script execution in the PDF viewer. The observed behavior is that an alert dialog is displayed. I did not observe cookie or DOM exfiltration — the issue manifests as arbitrary script execution limited to showing an alert in the viewer context.

Impact:
- Executes attacker-controlled JavaScript in the PDF viewer context.
- Observed impact in my tests: **alert dialog only** (no cookie/DOM exfiltration observed).

# Summary
PDF-based XSS / JavaScript execution via rendered PDF
