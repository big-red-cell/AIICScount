VULNERABILITY DETAILS<br>Opening a new tab and immediately activating a mailto: link can cause the external protocol handler prompt to appear over the wrong tab. Attackers can use this to mislead users about the origin of the prompt.<br><br>VERSION<br>Chrome Version: 141.0.7390.55 + stable<br>Operating System: Windows 10<br><br>REPRODUCTION CASE<br>1. Open poc.html in Chrome.<br>2. Click the &quot;Click Me&quot; button.<br>3. A new tab will open to <a href="https://www.google.com" target="_blank" rel="noopener noreferrer nofollow ugc" data-b-widget="url" data-b-original-href="https://www.google.com" data-b-redirected-href="https://www.google.com">https://www.google.com</a>.<br>4. Immediately after, the current tab will try to navigate to a mailto: link.<br><br>CREDIT INFORMATION<br>Reporter credit: Geva Nurgandi Syahputra (gevakun)
