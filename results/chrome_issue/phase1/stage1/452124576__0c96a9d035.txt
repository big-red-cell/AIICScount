### The problem


#### Please describe the technical details of the vulnerability

Subject: Chrome — drive.google.com showing unrelated users’ people details (names, profile info, timestamps)

Product: Chrome / Google Drive (drive.google.com)
Severity: High — Privacy leak (PII exposure)

Summary:
While using Chrome to access drive.google.com, I noticed that under certain conditions, people-related details (names, profile pictures, timestamps, or metadata) from other users appear in my view. This seems to be a privacy issue exposing personal information without authorization.

Environment:
- Chrome version: <your Chrome version>
- OS / Device: <Android / Windows / macOS + version>
- Account used: Account A (primary/test)
- Affected URL(s): drive.google.com (example link: <insert link>)

Steps to Reproduce:
1. Sign in to Chrome with Account A.
2. Go to drive.google.com and open a shared folder or file.
3. (Optional) Switch profile or open via “Shared with me.”
4. Notice that unrelated people details (names, profile info, timestamps) from another user (Account B) appear.

Actual Result:
Unrelated user information (names, profile pictures, timestamps) is visible to me without explicit sharing.

Expected Result:
Only files and details explicitly shared with my account should be visible. Other users’ people data should not appear.

Proof / Attachments:
- Screenshot(s): attached (blurred where necessary)
- Screen recording: attached (if available)
- Affected URLs and timestamps: included below

Impact:
Privacy breach — exposure of personally identifiable information (names, profiles, timestamps). Potential risk of data leakage or identity exposure.
