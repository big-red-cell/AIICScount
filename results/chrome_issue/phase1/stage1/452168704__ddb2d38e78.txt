<h1>Problem Description</h1>
<p>A download initiated by a hidden iframe and followed by an immediate redirect allows the visible tab to display a different (benign) origin while the browser’s download prompt or Downloads list shows a file from the original download origin.</p>
<p>This mismatch in visible tab context versus download source can be used to mislead users about the true origin of the downloaded file, effectively creating a download origin spoofing or UI confusion scenario.</p>
<p>This is similar in nature to the previously reported issue [<a href="https://crbug.com/40055527" target="_blank">crbug.com/40055527</a> – “File Download Pop-up Origin Spoof”].</p>
<h1>Summary</h1>
<p>Download origin spoof via hidden iframe + immediate redirect (UX confusion / spoof risk)</p>
