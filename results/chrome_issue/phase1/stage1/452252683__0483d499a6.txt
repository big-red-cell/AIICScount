<h3>The problem</h3>
<h4>Please describe the technical details of the vulnerability</h4>
<p>The Chrome extension “Instant Bitcoin Generator Free” simulates Bitcoin mining and payouts using a spoofed UI. It references a backend domain (bitcoinlive-app.xyz) that is inactive and listed for sale. The extension loads a static HTML dashboard (index.html) that displays hardcoded Bitcoin addresses, timestamps, and payout amounts. No backend calls are made, and no mining logic exists.
The extension requests no permissions, yet simulates sensitive financial behavior. This misleads users into believing they are earning cryptocurrency, violating Chrome Web Store trust policies and creating a potential vector for phishing, crypto scams, or deceptive monetization.</p>
<h4>Impact analysis – Please briefly explain who can exploit the vulnerability, and what they gain when doing so</h4>
<p>Any user who installs the extension “Instant Bitcoin Generator Free” is exposed to deception. The extension simulates Bitcoin payouts using hardcoded data and references a backend domain that does not exist. Users may falsely believe they are mining or earning cryptocurrency, which can lead to financial decisions based on fake trust signals. This opens the door for phishing, crypto scams, or future monetization through misleading UI and false backend claims.</p>

<h4>What version of Chrome have you found the security issue in?</h4>
