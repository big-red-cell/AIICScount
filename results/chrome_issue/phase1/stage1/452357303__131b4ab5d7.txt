<p>Yeah, guess what <code>--experimental-wasm-skip-null-checks</code> does? It skips null checks. So we will run into all kinds of issues if a null value reaches places it wouldn&#39;t reach otherwise. The failed <code>CSA_DCHECK</code> is one such place, we reach it with the <code>WasmNull</code> value instead of a valid <code>WasmFuncRef</code>.</p>
<p>Please do not use such flags for fuzzing.</p>
