<h1>Steps to reproduce the problem</h1>
<ol>
<li>Create a QR code encoding a malicious URL (example: <code>https://hackerbro.net or https://evil.example</code>).</li>
<li>Open <strong>Chrome → QR Code Scanner</strong> on Android.</li>
<li>Scan the QR code.</li>
<li>Observe that Chrome displays the QR-coded link (or overlays it), and if the user taps that link the browser redirects to the attacker-controlled domain <strong>without showing a confirmation dialog or asking the user to Allow or Deny</strong>.</li>
</ol>
<p><strong>Expected Behaviour:</strong></p>
<ul>
<li>Chrome should display a clear confirmation dialog showing the full canonicalized URL and require an explicit user action (e.g., <strong>Allow / Deny</strong>) before opening the scanned link.</li>
</ul>
<h1>Problem Description</h1>
<ul>
<li>During my research on <strong>Chrome version 141.0.7390.122 (Android)</strong>, I discovered an <strong>open redirect vulnerability</strong> in the built-in QR code scanner.</li>
<li>When a QR code containing an external or malicious URL is scanned, Chrome displays the QR-coded link (or overlays it), and if the user taps that link the browser redirects to the attacker-controlled domain <strong>without showing a confirmation dialog or asking the user to Allow or Deny</strong>.</li>
</ul>
<p><strong>Impact:</strong></p>
<ul>
<li>An attacker can craft QR codes that silently redirect users to <strong>phishing pages, drive-by downloads, or malware-hosting sites</strong>, increasing the risk of credential theft, device compromise, and privacy loss.</li>
</ul>

</li>
<li>
<p>Chrome isn&#39;t scanning the QR code, Google Lens (part of the Google Search App) is, and it then has Chrome open the specified URL. Google Lens is displaying the origin of the QR code before the user taps on it, so the user can choose to not open the link at that point in time.</p>
</li>
<li>
<p>Other Android apps are allowed to send intents to Chrome to open an URL, and Chrome doesn&#39;t require action before opening such a URL. It&#39;s irrelevant that the intent Chrome received was from Google Lens (or the Google Search App) after it scanned a QR code.</p>
</li>
</ol>
