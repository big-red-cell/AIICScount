Author: nobody@google.com
<p>When the user clicks the link for <code>http://httpbin.org/response-headers</code>, that request is a same-site navigation to httpbin.org. When the user then opens <code>http://httpbin.org/headers</code>, that is another navigation to httpbin.org. Both of those requests are same-site requests, and they are both for the same site, httpbin.org. This is working as intended.</p>
