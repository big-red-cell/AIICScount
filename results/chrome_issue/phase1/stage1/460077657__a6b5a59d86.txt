<h3>The problem</h3>
<h4>Please describe the technical details of the vulnerability</h4>
<p>When a user logs into Chrome on a shared or public computer (e.g., library PC) using their Google account and enables sync, all their bookmarks, settings, and saved passwords are synchronized to the browser. If the user forgets to sign out or disable sync, another person using the same computer account (e.g., a generic Windows account) can access the Chrome settings and open Google Password Manager without being prompted for the original Google account credentials.
This effectively allows unauthorized access to sensitive credentials stored in Google Password Manager. The issue occurs because Chrome relies on the OS-level authentication for password viewing rather than enforcing Google account re-authentication. On shared devices, this creates a significant security risk.</p>
<h4>Impact analysis – Please briefly explain who can exploit the vulnerability, and what they gain when doing so</h4>
<p>Everyone can gain access to your passwords and by doing so they can get acces to all your accounts!</p>
