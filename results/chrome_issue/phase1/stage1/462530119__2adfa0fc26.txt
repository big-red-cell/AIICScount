<h3>The problem</h3>
<h4>Please describe the technical details of the vulnerability</h4>
<p>I identified a security issue related to password management. The browser’s autocomplete for username and password allows the password to be viewed in plain text without authenticating with the password manager. A user only needs to open the developer tools and change the field from type=&quot;password&quot; to type=&quot;text&quot;.</p>
<p>There are additional methods to retrieve the password, such as executing JavaScript through the developer tools using a querySelector on the password field, or even through the URL. This means that the password can be exposed on mobile devices as well, without requiring authentication in the password manager.</p>
<h4>Impact analysis – Please briefly explain who can exploit the vulnerability, and what they gain when doing so</h4>
<p>You see any password saved on password management without authentication.</p>
