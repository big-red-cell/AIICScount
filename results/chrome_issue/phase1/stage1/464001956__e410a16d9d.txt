<li>Open my test.html attachments on chrome browser</li>

<h1>Problem Description</h1>
<p>Hi team!
I discovered an origin spoof vulnerability by exploiting the DOM event listener, which prevents the original link from opening. So here, when users click on the link, they will think they are actually on the official facebook.com page. However, by using the JavaScript event listener, we can prevent the facebook.com link from opening and redirecting to another page.</p>
