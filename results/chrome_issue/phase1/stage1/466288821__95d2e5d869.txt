<h1>Problem Description</h1>
<p><strong>chrome://downloads</strong> page contains the files that were downloaded. Each downloaded file is enclosed in a card, that would have the file&#39;s name and the site from which it&#39;s downloaded.
Attacker can <strong>hide</strong> the site&#39;s address that triggered the file to download by using the <code>window.location.replace(&quot;attacker-site.com&quot;)</code> before the file downloads begins.
<em>Expected behaviour</em>: The site address must appear below the file name
<em>Acutal behaviour</em>: The site address is not appearing</p>
<h1>Summary</h1>
<p>Site address from where a file is downloaded can be hidden on the cards in the chrome://downloads</p>
