<h1>Problem Description</h1>
<p><code>documentPictureInPicture</code> requires a User gesture like click or key press to open it.  But, it can be opened by combining the <code>timeout</code> API and opening a link in Split view.
By placing the <strong>documentPictureInPicture</strong> in <code>timeout</code> API, if the user is convinced to right-click on a link on the page and open it <strong>Split View</strong> within the set time in seconds for the timeout API to trigger, then <code>documentPictureInPicture</code> popup shows over the browser.</p>
<h1>Summary</h1>
<p>documentPictureInPicture can be opened without user gesture while Split view is active</p>
