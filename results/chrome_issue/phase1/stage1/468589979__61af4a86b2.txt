<p>Description
An access control bypass allows authenticated users to view group names (and potentially other group metadata) they shouldn&#39;t have access to by modifying URL parameters. The application fails to properly validate group membership/authorization when direct object references are used in URLs.</p>
<p>Impact</p>
<pre><code>Confidentiality: Medium - Unauthorized disclosure of group names/existence
Attack Vector: Low-privileged authenticated user
Prerequisites: Valid user account
</code></pre>
<p>Root Cause Analysis</p>
<pre><code>Missing server-side authorization checks for group view permissions
</code></pre>
