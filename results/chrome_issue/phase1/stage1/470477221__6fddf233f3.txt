<h1>Problem Description</h1>
<p>A web page can open multiple browser windows from a single click.
By carefully controlling their size, position, and timing, these windows can appear visually connected, giving the impression of a single interface.</p>
<p>This behavior can lead to visual UI spoofing, where content from separate windows may look like it belongs to the same page, even though each window is actually independent and loaded from a different origin.</p>
<h1>Summary</h1>
<p>UI Spoofing via <code>window.open()</code> Visual Deception</p>
