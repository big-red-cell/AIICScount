<h1>Steps to reproduce the problem</h1>
<ol>
<li>Enable the flag #open-dragged-links-same-tab</li>
<li>Upload the file to your server and drag and drop the POC link file into another tab. (If it is to an authenticated tab, it will be more dangerous)</li>
<li>The active tab is silently redirected to attacker’s page, no confirmation or prompt.</li>
</ol>
<h1>Problem Description</h1>
<p>Chrome flag #open-dragged-links-same-tab enables automatic navigation when a link is dragged into an existing tab. However, this behavior allows an attacker to silently hijack the current tab by tricking the user into dragging a malicious link, causing instant redirection without any confirmation or gesture-based intent.</p>
<p>This breaks user expectations and opens the door for UX-deception-based attacks (e.g. tab takeover, session exfiltration) since navigation occurs without explicit user action (e.g., click).</p>
<h1>Summary</h1>
<p>Drag-and-drop flag link navigation leads to hijack (macOS)</p>
