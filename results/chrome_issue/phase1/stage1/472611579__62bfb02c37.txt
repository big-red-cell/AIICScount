<p>Title</p>
<p>Maglev: %OptimizeMaglevOnNextCall crashes when called with non-JSFunction (CHECK(IsJSFunction) failure)</p>
<p>Product</p>
<p>V8</p>
<p>Component</p>
<p>Blink&gt;JavaScript (or V8&gt;Maglev if selectable)</p>
<p>V8 Version</p>
<p>14.5.0 (candidate)</p>
<p>d8 version: V8 version 14.5.0 (candidate)</p>
<p>Environment</p>
<p>OS: Windows 10 x64</p>
<p>Architecture: x64</p>
<p>Build: win64-debug (ASAN-enabled)</p>
<p>Shell: d8.exe</p>
<p>Flags Used
--maglev
--print-maglev-graph
--allow-natives-syntax</p>
<p>Summary</p>
<p>Calling %OptimizeMaglevOnNextCall with a value that is not a JSFunction leads to a fatal CHECK failure in runtime-test.cc. The engine crashes instead of throwing a JavaScript exception or gracefully rejecting the input.</p>
<p>This indicates insufficient runtime validation in the Maglev optimization entrypoint and suggests a broken assumption about value types reaching the optimizer.</p>
<p>Steps to Reproduce</p>
<p>Build or obtain a debug d8 binary with Maglev enabled.</p>
<p>Save the following PoC as poc83.js</p>
<p>Run:</p>
<p>d8.exe poc83.js --maglev --allow-natives-syntax --print-maglev-graph</p>
<p>Proof of Concept
const v1 = new Set();</p>
<p>for (let v2 = 0; v2 &lt; 5; v2++) {
function F3() {
this.a = -869472841;
}</p>
<pre><code>const v6 = new F3();

    const o12 = {

var a = f7(v6);

%OptimizeMaglevOnNextCall(f7(a));

<p>}</p>
<p>Observed Behavior</p>
<p>V8 crashes with a fatal error:</p>
<p>Fatal error in src/runtime/runtime-test.cc, line 390
Check failed: IsJSFunction(*function_object).</p>
<p>The process terminates immediately.</p>
<p>Expected Behavior</p>
<p>One of the following should occur instead:</p>
<p>A JavaScript TypeError</p>
<p>Graceful rejection of the optimization request</p>
<p>Early bailout with proper input validation</p>
<p>The runtime should not crash due to invalid user-controlled input.</p>
<p>Stack Trace (Excerpt)
OptimizeFunctionOnNextCall
Runtime_OptimizeMaglevOnNextCall
Builtins_CallRuntimeHandler
Builtins_InterpreterEntryTrampoline
Shell::ExecuteString</p>
<p>Analysis / Notes</p>
<p>%OptimizeMaglevOnNextCall assumes its argument is a JSFunction</p>
<p>The PoC passes a plain object, constructed via:</p>
<p>Object spread</p>
<p>Computed property name using a heap object</p>
<p>Explicit prototype mutation</p>
<p>The runtime entrypoint does not sufficiently validate the argument before asserting</p>
<p>Although this manifests as a CHECK failure in debug builds, similar assumption violations in JIT entrypoints have historically led to type confusion or memory safety issues in optimized/release configurations.</p>
<p>Reproducibility</p>
<p>Reproduces 100% of the time</p>
<p>No GC, timing, or race dependence</p>
<p>Security Impact</p>
<p>Potentially security-relevant. Crashing on invalid JS-visible input indicates a broken internal invariant in Maglev’s optimization pipeline. Similar issues in the past have escalated beyond CHECK-only failures.</p>
