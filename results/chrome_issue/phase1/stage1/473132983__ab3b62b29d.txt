<p>Integer Overflow in PDFium JBIG2 Decoder Leading to Heap Buffer Overflow</p>

<h3>The problem</h3>
<h4>Please describe the technical details of the vulnerability</h4>
<p>An integer overflow vulnerability exists in PDFium&#39;s JBIG2 decoder that allows bypassing security checks through type confusion. The vulnerability is located at core/fxcodec/jbig2/JBig2_SddProc.cpp:451.</p>
<p>The vulnerable code uses static_cast<span>&lt;int&gt;</span>() on a uint32_t value to perform bounds checking:</p>
<p>if (static_cast<span>&lt;int&gt;</span>(TOTWIDTH) &gt; kJBig2MaxImageSize)
return nullptr;</p>
<p>When TOTWIDTH &gt;= 0x80000000, the cast to signed int produces a negative value, causing the comparison to fail and bypassing the security check. This allows creation of invalid image objects leading to heap buffer overflow.</p>
<p>TECHNICAL DETAILS:</p>
<ul>
<li>The TOTWIDTH variable accumulates symbol widths from a JBIG2 Symbol Dictionary</li>
<li>By crafting a dictionary with 32,769 symbols each 65,535 pixels wide, TOTWIDTH reaches 0x80007FFF (2,147,516,415)</li>
<li>When cast to int32_t, this becomes -2,147,450,881 (negative)</li>
<li>The check &quot;negative &gt; 65535&quot; evaluates to FALSE, bypassing the intended protection</li>
<li>Subsequently, CJBig2_Image allocation fails with invalid parameters</li>
<li>This leads to NULL pointer dereference and memory corruption</li>
</ul>
<h4>Impact analysis</h4>
<p>SECURITY IMPACT:</p>
<ul>
<li>Remote Code Execution potential</li>
<li>Heap buffer overflow</li>
<li>Memory corruption</li>
<li>Denial of Service (crash)</li>
<li>Affects all Chrome users who open malicious PDFs</li>
</ul>
<p>ATTACK SCENARIO:</p>
<ol>
<li>Attacker hosts or sends a malicious PDF with crafted JBIG2 stream</li>
<li>Victim opens the PDF in Chrome browser or Chrome PDF viewer</li>
<li>PDFium JBIG2 decoder processes the malicious Symbol Dictionary</li>
<li>Integer overflow bypasses security check (line 451)</li>
<li>Invalid image allocation causes heap corruption</li>
<li>Potential for arbitrary code execution or information disclosure</li>
</ol>
<p>AFFECTED USERS:</p>
<ul>
<li>All Chrome desktop users</li>
<li>All Chrome OS users</li>
<li>Android Chrome users opening PDFs</li>
<li>Any application using PDFium library</li>
</ul>
