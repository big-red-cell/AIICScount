<h1>Steps to reproduce the problem</h1>
<ol>
<li>Open <code>chrome://contextual-tasks/</code> in Chrome.</li>
<li>Create/submit a task with a custom <code>title</code> value (e.g. <code>GOOGLE HACKED</code>, <code>chrome://version</code>, or <code>https://google.com</code>).</li>
<li>Observe the omnibox after submission.</li>
</ol>
<h1>Problem Description</h1>
<p>The omnibox displays the user-controlled <code>title</code> parameter instead of reflecting the actual
navigation state (<code>chrome://contextual-tasks</code>). This allows arbitrary text (including URLs or
system-like strings) to appear in the omnibox while the content remains unchanged, violating
trusted UI guarantees and potentially confusing users about the active page or origin.</p>
<h1>Summary</h1>
<p>Omnibox displays arbitrary text via chrome://contextual-tasks title parameter (UI spoofing)</p>
