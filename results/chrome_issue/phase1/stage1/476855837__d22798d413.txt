# Problem Description
Description:-
I have discovered a Use-After-Free (UAF) vulnerability in the CSSStyleSheet interface. When a <style> element containing an @import rule is removed from the DOM, the imported CSSStyleSheet object remains accessible and interactive via JavaScript references, despite its conceptual owner being destroyed. While the browser's MiraclePtr/PartitionAlloc hardening prevents an immediate crash (Heap Corruption is mitigating), I successfully demonstrated a Write-After-Free primitive by toggling the disabled property on the freed stylesheet object.

Impact:-
This is a logic error in the object lifecycle management that leaves a "Zombie" object in memory. An attacker can exploit this to perform UAF read/write operations. With precise heap grooming (demonstrated in the attached exploit_uaf_crash_attempt.html), this can lead to arbitrary code execution or renderer compromise.
