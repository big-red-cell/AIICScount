<p>Occasional NaNs canonicalization is non-random.</p>
<p>It can detect in a very fine-grained and reproducible way:</p>
<ol>
<li>If devtools are open or not (including for other tabs in the same process)</li>
<li>Individual <code>for (let i=0;i&lt;3;i++);</code> blocks</li>
<li>Individual <code>for (let i=0;i&lt;1;i++);</code> blocks by offsetting the tripping point</li>
</ol>
<p>While 2-3 appear like timing at the first glance, this <strong>does not</strong> appear to be timing-related after checks on linear code. Only loops, including the code inside the loop, including unreachable code, affect the observed side-channel value. Linear code, including function calls, doesn&#39;t.</p>
<p><strong>My current assumption is that NaNs canonicalization leaks calculated budget value in high-precision.</strong></p>
<p>I am not aware of a way to abuse apart from devtools detection, but reporting as a security issue instead of a public one to be on the safer side.</p>
<p>Note that the initial observation that the results appear non-deterministic is public here: <a href="https://github.com/tc39/ecma262/pull/758#issuecomment-3919093669" data-b-widget="url" data-b-original-href="https://github.com/tc39/ecma262/pull/758#issuecomment-3919093669" data-b-redirected-href="https://www.google.com/url?q=https://github.com/tc39/ecma262/pull/758%23issuecomment-3919093669&amp;sa=D&amp;source=buganizer&amp;usg=AOvVaw15MtYmHqvhcqYbzEK8gEXh">https://github.com/tc39/ecma262/pull/758#issuecomment-3919093669</a> <br>
(but without details that it leaks something usable, I wasn&#39;t aware of it when I posted that comment).</p>

<p>This &quot;occasional&quot; canonicalization is the source of the problem here, the non-deterministic channel leaks internal state and allows extracting details about internal state, including cross-origin</p>
<p>To fix this, remove any observable no-ndeterminism with NaNs, and if they could be internally canonicalized (by e.g. PACKED_DOUBLE_ELEMENTS optimization), then make <code>SetValueInBuffer</code> <em>always</em> canonicalize to hide internal state.</p>
