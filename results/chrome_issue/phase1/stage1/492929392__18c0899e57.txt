<h3>The problem</h3>
<h4>Please describe the technical details of the vulnerability</h4>
<p>The &quot;Edit as HTML&quot; functionality in Chrome DevTools does not sufficiently sanitize input, allowing attackers to inject and execute arbitrary JavaScript on any inspected page.
Steps to Reproduce:</p>
<ol>
<li>Open <a href="https://www.google.com" data-b-widget="url" data-b-original-href="https://www.google.com" data-b-redirected-href="https://www.google.com/url?q=https://www.google.com&amp;sa=D&amp;source=buganizer&amp;usg=AOvVaw0xHc4PnJ-5PnGXiIvS00h7">https://www.google.com</a> in Google Chrome.</li>
<li>Press F12 to open DevTools.</li>
<li>In the Elements tab, right-click the <span>&lt;body&gt;</span> element and select Edit as HTML.</li>
<li>Delete the existing content and paste the following payload:</li>
</ol>
<div>&lt;img src=x onerror=&quot;alert(&#39;DevTools XSS Confirmed - &#39; + document.domain)&quot;&gt;
5. Click anywhere outside the editor to apply the changes.
6. An alert box will appear containing &quot;DevTools XSS Confirmed - www.google.com&quot;.
</div>
<h4>Impact analysis</h4>
<p>This vulnerability allows a malicious website to execute arbitrary JavaScript in the context of the page when a developer opens DevTools and uses &quot;Edit as HTML&quot;. Potential consequences include session theft, credential stealing, or full account takeover.</p>
