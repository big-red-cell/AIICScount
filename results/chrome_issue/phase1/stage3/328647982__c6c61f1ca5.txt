### Report description


Skia global buffer overflow in SkString::append

### Bug location


#### Which product or website have you found a vulnerability in?

Google Chrome


#### Which URL (or repository) have you found the vulnerability in?

https://github.com/google/skia/

### The problem


#### Please describe the technical details of the vulnerability

The following PoC results in a global buffer overflow.   Build Skia program with ASAN
```
#include "SkString.h"

int main() {
    // Create an SkString instance
    SkString myString("Hello");

    // Append some text to the string
    myString.append("Hello", 65536);
    return 0;
}
```
results in the following ASAN output:
