VULNERABILITY DETAILS<br>This vulnerability arises from the fact that local HTML files are not subject to the same restrictions as web-hosted pages, which enables them to freely access local file system paths via script tags. An attacker can craft a malicious HTML file that systematically targets a range of common file system paths (e.g., system directories, installed software locations) by creating &lt;script&gt; elements with their src attributes set to these paths.<br><br>The key mechanism that enables this enumeration is the use of JavaScript events, specifically the onload and onerror events associated with &lt;script&gt; tags. When a script tag attempts to load a file:<br><br>The onload event is triggered if the file exists and is successfully loaded, indicating that the target file or directory is present.<br>Conversely, the onerror event fires if the file does not exist or is inaccessible, thereby signaling its absence.<br>By monitoring these events, the malicious HTML file can build an accurate map of the victim&#39;s file system. In addition, file and folder names can be obtained by brute forcing potential names, and the use of Windows short file names (the 8.3 filename format) further simplifies this process. This method can also be employed to check if specific vulnerable software or browser extensions are installed on the system. If a vulnerable browser extension is detected, the malicious page can leverage that discovery to continue exploiting the extension for further attacks.<br><br>The collected data detailing which files or directories exist can then be exfiltrated to an attacker-controlled server via a simple JavaScript HTTP POST request. This process enables an attacker to silently enumerate and harvest sensitive information about the victim’s file system in the background, without any user interaction or awareness.<br><br>Simple Code Example:<br><br>&lt;script&gt;<br>  var f = &quot;C:\\Windows\\System32\\calc.exe&quot;;<br>  var s = document.createElement(&quot;script&quot;);<br>  s.src = f;<br>  s.onload = () =&gt; console.log(f + &quot; exists&quot;);<br>  s.onerror = () =&gt; console.log(f + &quot; does not exist&quot;);<br>  document.body.appendChild(s);<br>&lt;/script&gt;<br><br>VERSION<br>Chrome Version: Version 132.0.6834.160 (Official Build) (64-bit) + stable<br>Operating System: Windows 10 Home Single Language <br>Version: 22H2<br><br>REPRODUCTION CASE<br>1.
