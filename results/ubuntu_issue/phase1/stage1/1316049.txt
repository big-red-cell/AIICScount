Bug #1316049: Screen locking issue in VM with VirtualBox

URL: https://bugs.launchpad.net/ubuntu/+source/gnome-screensaver/+bug/1316049

Metadata: security_related=true; information_type=Public Security; tags=["apport-bug", "i386", "precise", "running-unity"]; targets=gnome-screensaver (Ubuntu) (Won't Fix, Undecided)

Description:
I'm running 12.10 in a VirtualBox vm with automatic adaption of the guest's screen size. When I started some program in Windows (host) and accidentially changed the window size of the Ubuntu VM from fullscreen to window and back the lockscreen did not change the resolution back to fullscreen although the desktop did. As a result I was able to use the desktop as the lockscreen did not cover the whole screen. Unfortunalely, I did not make a screenshot and I cannot reproduce the described behaviour.
