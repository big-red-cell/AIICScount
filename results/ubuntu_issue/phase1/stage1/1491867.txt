Bug #1491867: Update manager starts runs and updates software without authentication

URL: https://bugs.launchpad.net/ubuntu/+source/update-manager/+bug/1491867

Metadata: security_related=true; information_type=Public Security; tags=["amd64", "apport-bug", "wily"]; targets=update-manager (Ubuntu) (Won't Fix, Undecided)

Description:
No password is required and no authorization window ever opens when updating software with the update manager.   Update manager was opened from the main menu via mouse click without using sudo or root. Updatable software was found , I clicked install updates and updates were uploaded and installed by update manager without admin authorization.  Two hours later I repeated the process and it updated without asking for authorization/password.
Extra info: This is a fresh installation of Ubuntu studio wily. No preference changes have been made. I use automatic login when booting.  All of the other processes that I have tried and  which usually require password authorization are functioning as expected

DistroRelease: Ubuntu 15.10
Package: update-manager 1:15.04.7

Message 3 | Author: seth-arnold | Subject: Re: Update manager starts runs and updates software without authentication
This is intentional behaviour; only updates for already installed software can be applied without a password. Installing additional software still requires people to enter their password.

For more information, please see https://wiki.ubuntu.com/SecurityTeam/FAQ#Update_Manager_doesn.27t_prompt_for_security_updates
