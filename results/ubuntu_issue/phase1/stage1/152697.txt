Message 3 | Author: laga | Subject: Re: mythtvbackend leaves open ports to the internet by default
I can reproduce this on 0.21. Unfortunately, upstream thinks this is not an issue: http://svn.mythtv.org/trac/ticket/2031

There's a patch attached to that ticket: http://svn.mythtv.org/trac/attachment/ticket/2031/myth-interface.patch

I'm not sure if just binding to one interface wouldn't break some setups.. while the backend currently listens on all interfaces, I was under the impression it was not possible to serve more than one network from one backend because you can only specify one IP address for the master backend. Unless you do some clever routing/iptables stuff, of course. It'll probably break for people who query the backend status page from other networks, though.
