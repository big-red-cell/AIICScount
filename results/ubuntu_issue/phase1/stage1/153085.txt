Bug #153085: [openssl security] Off-by-one error in the DTLS implementation (CVE-2007-4995)

URL: https://bugs.launchpad.net/ubuntu/+source/openssl097/+bug/153085

Metadata: security_related=true; information_type=Public Security; targets=openssl (Ubuntu) (Fix Released, High), openssl097 (Ubuntu) (Won't Fix, Undecided)

Description:
Off-by-one error in the DTLS implementation in OpenSSL 0.9.8 before 0.9.8f and 0.9.7 allow remote attackers to execute arbitrary code via unspecified vectors. http://nvd.nist.gov/nvd.cfm?cvename=CVE-2007-4995.

I couldn't find changelog entry describing CVE-2007-4995 as fixed, so it probably isn't yet.
Gutsy,Feisty,(Edgy) and Dapper are affected.
