Description:
Seems last update from upstream made -pie be disabled.
You can check if it's the case running hardening-check /usr/sbin/mysqld:

 Position Independent Executable: no, normal executable!
 Stack protected: yes

 Read-only relocations: yes
 Immediate binding: yes

As above, PIE is disabled for some reason.
