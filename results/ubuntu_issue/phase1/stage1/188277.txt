Bug #188277: Keyring manager is kind of corrupt

URL: https://bugs.launchpad.net/ubuntu/+source/gnome-keyring-manager/+bug/188277

Metadata: security_related=true; information_type=Public Security; tags=["apport-bug"]; targets=gnome-keyring-manager (Ubuntu) (Won't Fix, Medium)

Description:
I wanted to change my keyring password, but there was no option for it in the keyring manager. I clicked the line that said "Unlock password for default keyring" which I expected to give me the option to change the password, but the lower area of the window turned blank.

Then I thought "maybe it for some reason ought to be impossible to change a keyring password". So I decided I could risk starting the password collecting from scratch, and removed the key (not keyring). At first it seemed to only remove the "unlock key", but when I tried to restart the program or create a new key (sorry, I do not remember the order), nothing showed up.

Moreover, this whole process seemed to change my administrator password, if that is at all possible from its position, which is not a good thing. I was certain I did not change the admin password as late as the day before. If I am right, the administrator password was set to the same as the new keyring.

I realize that the problem with blank key list may be only bad UI, because from the menu I could find all the keys again. I suggest that the list of keyrings pops up automatically from program start, at least under certain conditions (having multiple keyrings with keys?). And that it is made possible/easier to change the password for a keyring. And a total drag-and-drop-functionality for keys and keyrings from the administrator perspective. :-)
