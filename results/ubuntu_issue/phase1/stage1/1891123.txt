Message 2 | Author: mdeslaur | Subject: Re: Openssh vulnerability on ubuntu 16.04
Hi,

The only thing an attacker can do with this vulnerability is DoS their own connection. As such, it is not considered a security issue either by the upstream OpenSSH project, or by the Ubuntu security team.

Like other distros, we have no plans to fix this issue in our stable releases.
