Bug #197758: firefox crashes: BadAlloc (insufficient resources for operation)

URL: https://bugs.launchpad.net/ubuntu/+source/firefox/+bug/197758

Metadata: security_related=true; information_type=Public Security; targets=firefox (Ubuntu) (Won't Fix, Undecided)

Description:
here is a page that we managed to generate using mediawiki, when we forgot to close a tex tag. It reproducably crashes firefox 2 & 3 with:
The program 'firefox' received an X Window System error.
This probably reflects a bug in the program.
The error was 'BadAlloc (insufficient resources for operation)'.
  (Details: serial 8269 error_code 11 request_code 53 minor_code 0)
  (Note to programmers: normally, X errors are reported asynchronously;
   that is, you will receive the error a while after causing it.
   To debug your program, run it with the --sync command line
   option to change this behavior. You can then get a meaningful
   backtrace from your debugger if you break on the gdk_x_error() function.)

erroneus page attached.
