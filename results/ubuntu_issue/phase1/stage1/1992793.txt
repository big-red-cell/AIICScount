Bug #1992793: world readable /var/lib/ubuntu-advantage/machine-token.json

URL: https://bugs.launchpad.net/ubuntu/+source/ubuntu-advantage-tools/+bug/1992793

Metadata: security_related=true; information_type=Public Security; targets=ubuntu-advantage-tools (Ubuntu) (Won't Fix, Undecided)

Description:
I noticed that on systems where I had 'ua' enabled that were recently upgraded with 'pro' that machine-token.json is now in both /var/lib/ubuntu-advantage and /var/lib/ubuntu-advantage/private, but the file permissions are world-readable (0644) for /var/lib/ubuntu-advantage/machine-token.json. Since /var/lib/ubuntu-advantage is also world-readable, so is /var/lib/ubuntu-advantage/machine-token.json.

Ie:

# /var/lib/ubuntu-advantage/private/machine-token.json is safe
$ id -u
1000
$ cut -d : -f 1 /var/lib/ubuntu-advantage/private/machine-token.json
cut: /var/lib/ubuntu-advantage/private/machine-token.json: Permission denied

# /var/lib/ubuntu-advantage/machine-token.json is not
$ cut -d : -f 1 /var/lib/ubuntu-advantage/machine-token.json
{"machineTokenInfo"

I noticed this is true on 16.04 and 18.04, but presumably it is true in ubuntu-advantage-tools 27.12.2 (I didn't check).

Message 4 | Author: orndorffgrant | Subject: Re: world readable /var/lib/ubuntu-advantage/machine-token.json
Hey sorry this slipped through the cracks. This is not an issue - it is just a poorly named file :)

The world readable "machine-token.json" is there on purpose. It is a different size because it is only a subset of the information in the private machine-token.json. Most importantly, the actual secret tokens are not present in the world readable version of the file. You can confirm this by comparing the contents of the private and world-readable machine-token.json files.

The pro client stores a lot more than just the secrets and sensitive information in machine-token.json (which is why I call it a poorly named file). The reason that there is now a world-readable version of the file with secrets stripped is to support giving an accurate status from the `pro status` command for non-root users.

Please let us know if you notice anything that should not be in the world readable machine-token.json file.
