Message 5 | Author: jdstrand | Subject: Re: anyone can gain root access to your system by selecting "recovery mode" grub option
This is a design feature of Ubuntu. Prompting for a root password in recovery mode on its own is specious, as a user need only insert a live cd, usb key, use 'init=/bin/sh' on the kernel command line or any number of other things. If you would like to set a root password for your root account, you may do so and you will be prompted.
