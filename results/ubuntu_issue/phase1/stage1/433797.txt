Bug #433797: cupsd.conf: "Require valid-user" ignored; other Require options work

URL: https://bugs.launchpad.net/ubuntu/+source/cups/+bug/433797

Metadata: security_related=true; information_type=Public Security; targets=cups (Ubuntu) (Won't Fix, Low)

Description:
If I put this in cupsd.conf:

<Location />
  Allow all
  Require valid-user
  Order allow,deny
  Allow all
</Location>

I can still view most[1] cups URLs without being prompted for credentials ([1] in /admin I have another Require directive that actually works). I validated via /var/log/cups/access_log that my browser isn't sending any cached credentials. It appears that "Require valid-user" is completely ignored by cups.

However, if I modify this to "Require user swarren" or "Require user @SYSTEM", those directives are honored, and I do have to enter credentials in my browser simply to access /, as I desire.
