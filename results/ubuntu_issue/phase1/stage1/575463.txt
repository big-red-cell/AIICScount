Bug #575463: When encrypting the home directory, /tmp nor /var/tmp is encrypted

URL: https://bugs.launchpad.net/ubuntu/+source/ubiquity/+bug/575463

Metadata: security_related=true; information_type=Public Security; targets=ubiquity (Ubuntu) (Won't Fix, Wishlist)

Description:
Currently when you tell ubuntu to encrypt your home directory, it also encrypts the swap via dmcrypt. While this is the right approach, /tmp nor /var/tmp are encrypted, which can left senisble data in those directories written by user applications. Ubuntu should also take care to encrypt those directories.

Discussion:
Message 2 | Author: jdstrand | Subject: Re: When encrypting the home directory, /tmp nor /var/tmp is encrypted
While I agree with the sentiment, what should really be used is full disk encryption in this case. This is available via the alternate installer. Optionally you can use the libpam-tmpdir package for per-user temporary directories. I am going to mark this bug as "Won't Fix" for now since there has been no activity on it for a year and developers are working on other features. Feel free to reopen if progress is made that a developer can incorporate into Ubuntu. Thanks!
