Message 6 | Author: pitti | Subject: Re: Security risk in mounting hard disks
This was actually done deliberately. On desktops we install the policykit-desktop-privileges package, which allows users to mount internal hard drives and set the system clock without having to authenticate. As in these environments you usually have physical hardware access anyway, there's not much to be gained from not allowing access here.

Please note that this doesn't apply to mkfs or partitioning changes, just mounting.
