Bug #63983: Dillo SSL Support is immature

URL: https://bugs.launchpad.net/ubuntu/+source/dillo/+bug/63983

Metadata: security_related=true; information_type=Public Security; targets=dillo (Ubuntu) (Won't Fix, Wishlist), dillo (Debian) (Fix Released, Unknown)

Description:
The SSL implementation of the Dillo web browser is insecure, and should not be enabled.

Flaws:

1) Dillo does not validate the common name of an SSL certificate.  If the CN of a certificate does not match the hostname used by a website, dillo does not report an error.  For an example, visit  https://www.alaskausafcu.org in both Firefox and Dillo.

2) Dillo does not validate the issuer of an SSLcertificate.  If you have a certificate signed by an untrusted certificate authority, dillo does not give an error.

3) Dillo does not notify users about expired SSL certificates.

There are most likely other flaws as well.

I spoke one of the authors of Dillo and his response was that there were many known issues with the SSL implementation in Dillo which is why SSL support is diabled by default.

Ubuntu should either turn off SSL support in Dillo or make it very clear that its SSL support is not to be trusted.
