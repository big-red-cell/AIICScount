Bug #840441: focus lost after tab key

URL: https://bugs.launchpad.net/ubuntu/+bug/840441

Metadata: security_related=true; information_type=Public Security; targets=Ubuntu (Won't Fix, Undecided)

Description:
when tasks are heavy, and after type something in edit object, and after type tab key, it should move the focus to next object that can receive focus, but sometimes, because of other tasks running heavy, the focus does not change, and the keys typed after the tab appear in the edit where the tab key was already typed...

It might seem a bug or flaw with no interest, but it is a major security breach, because, when I am in Firefox, and type, for example, at a login page, the user name, then press the tab key and type the password and then press the enter key, sometimes, I send the user name followed by the password, all in the same edit of the user name, which shows the password in screen and I think expose to the web the account combination...

All this could be avoid if the edit object would have a property that changed to true after the tab key is pressed, stopping further typing in that edit, even if have the focus...

Thank you for using Ubuntu and reporting a bug. While I appreciate the problem you have described, this is not something that can be fixed in Ubuntu as there is no unified 'edit object' that all programs use. Unfortunately, there is not a way to fix this uniformly in Ubuntu so individual applications must be modified, and these are not fixes we would carry in Ubuntu without being first fixed upstream (you might be interested in filing a bug with Mozilla about firefox). At this time, if your computer is under heavy load, you must simply be careful to notice where the input focus is.
