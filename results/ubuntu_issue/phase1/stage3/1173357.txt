Description:
We are getting a result back from a PCI scan indicating that our Postfix server on Lucid is vulnerable to CVE-2012-4929 on port 25.

As far as I can tell, there is no option to shut off TLS compression in either postfix or the SSL packages.

Release:	10.04

Message 2 | Author: seth-arnold | Subject: Re: Postfix in Lucid server vulnerable to CVE-2012-4929
I too was unable to find a postfix setting to disable compression, which seems odd, since there is a configuration for nearly everything else.

Some advice from the #postfix IRC channel on Freenode suggests disabling CBC mode ciphers; I do not know if this would be sufficient to pass the PCI audit or not, but it would go a long way towards mitigating the actual security problem. (I do not know that an attack is even remotely practical against SMTP; it seems like a long shot, since there is no equivalent of HTTP's session cookies, which made such an appealing target..)
